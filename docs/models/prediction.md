# 预测

给出预测分区间、差额与差距归因；2 期为 v0（基于掌握档与摸底），3 期为 v1（融合模考）。参数随 2 期规格登记。

## 输入 <a id="inputs"></a>
- 掌握档与证据充分性；考试画像的结构、题型与分值；知识点分值权重。
- 摸底估计与不确定度；模考成绩（v1）。
- 同类考生数据：只在没测到的模块代替，并标明（2.2）。

## 输出 <a id="outputs"></a>
- 预测区间（下限、上限）、中值、与目标的差额、可信度标签；各模块的差距贡献。

## 不变量 <a id="invariants"></a>
- 预测中的数字只来自本算法（INV-02）。
- 地图体检不通过时锁定预测，学习照常（S24-07）。
- 区间宽度反映不确定度：快速定位、证据不足都使区间变宽，并明说（S04-03）。

## 区间 <a id="interval"></a>
区间由各模块的期望得分与不确定度合成；证据不足的模块按同类考生数据代替，并计入不确定度。

## 差额 <a id="gap"></a>
差额 = 目标分 − 预测中值；归因按模块列出差距贡献，从大到小排列。

## 校准 <a id="calibration"></a>
考后成绩回填用于校准（3.5d）；预测区间覆盖率作为指标在后台监控。

## 降级 <a id="degradation"></a>
没有考情数据时不出性价比阶梯，改为按目标档差排序（3.2d）；样本不足时只显示原始计数。

## 验收方式 <a id="acceptance"></a>
- tests/models/prediction/ 保存回填样本，检查区间覆盖率与校准曲线。

## 补充引用的参数

- `learner.prior.min_population`：同类人数达到后改用群体先验（OQ-003）
- `learner.forecast.coverage_target`：预测区间覆盖率目标
- `learner.forecast.max_tier_jump`：性价比阶梯相邻两次重算的最大跳档
