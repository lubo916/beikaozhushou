# 文案约定

## 规则
1. 界面文案用文案键，不在组件里写死中文；术语以 docs/product/glossary.yaml 为准。
2. 不出现宣传禁用语（见 glossary 中“宣传禁用语”），不对考试结果作任何保证（INV-11）。
3. 提醒与断连回归不出现“落后”“欠”等字样，不展示累计未完成量。
4. 文案中的数字通过插值取自算法字段或参数，不写死。
5. 每项任务的理由用具体数字说明（考频、分值、档位差、到期时间），数字只来自算法（INV-02）。

## 示例
- 正例：“这一节考频高、你差两档，今天先学 25 分钟”，其中考频、档位差、时长都来自计划引擎的输出。
- 反例：三天没来，回来后首页显示“你已落后 47 项任务”：既有禁用字样，又展示了累计积压（S06-11、S35-02）。

## 理由
备考人群容易焦虑；理由可信、语气克制，才能让人每天愿意打开。宣传用语与结果承诺是监管红线。
