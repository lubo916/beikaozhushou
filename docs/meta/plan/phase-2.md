# 第 2 期 自助入门与“学”的闭环

> 受众环 ring-1+：扩大到 30 到 100 位受邀用户，仍不公开、不收费。 · 预算 170–230 轮 · 闭环 6 个 · 执行顺序 2.1 → 2.2 → 2.3 → 2.4 → 2.5 → 2.6

## 并行事项、门槛与决策点（按出现位置）

- **并行事项：确认种子教材文本的使用权**
  - 你：确认阅读器要用的文本都有使用权：自编讲义、官方公开的大纲与规范、已获授权的电子教材。拿不到授权就先用自编讲义。
  - Codex：更新 归档仓库 ops/seed-sources.md 的“教材文本”一行，给出文本整理成种子的模板。
  - 完成：种子教材文本的使用权状态为“已确认”（2 期进入条件）。
- **并行事项：安排危机信号的人工接手**
  - 你：导师上线前必须有人接手危机信号：设置风险信号实时通知到你的手机；准备核验过的求助信息（热线号码亲自打一遍核对）；约定收到信号后多久内处理。
  - Codex：写值守手册 归档仓库 ops/crisis-runbook.md：信号怎么到你手里、你第一步做什么、页面上展示什么、何时停止一切催学。
  - 完成：值守手册写好；你能在测试环境收到一条模拟的风险信号通知（2 期进入条件）。
- **受众环门槛：受众环 ring-1+ 门槛：可以扩大到 30–100 人**
  - 你：逐项确认门槛都已满足，缺一项就不扩大受众：不提前做（拖慢核心验证），也不拖后（挡住扩大受众）。
  - Codex：按门槛清单逐项给出证据（对应的测试、演练记录或文档）。
  - 完成：门槛清单全部满足：无人协助的入门（2.1）；导师的危机处置与生成标识（2.6）；值守安排（2 期值守）。
- **决策点：选路线：默认 A，还是 C（尽早公开或收费）、D（自建先行）**
  - 你：看商业判断选一条路线；不论选哪个，三条不变：0、1 期不动；安全随行不打折；闭环与切片的尺寸标准不变。
  - Codex：用你当前的数据（受邀用户反馈、探针 C 结论、付费意愿）对比各路线的代价。
  - 完成：写成 ADR（Codex 在主干用 new adr 分配编号）；如选 C 或 D，步骤表后续顺序按下面的说明调整。

## 本期的关键判断（分期规划原文）

- 入门流程为什么放在 2 期。入门的每一步都在给后面的循环喂数据：目标给计划，时间给排程，摸底给档位，报告给方案。1 期先用最薄的入门（四个字段加快速定位）撑住，等循环跑起来再把入门做完整，每一步才有去处。先做入门，就是先做一串没有下文的表单。
- 导师的“安全随行”包。2.6 不是“先上线、再补安全”。危机信号的识别与处置、生成内容标识、不可用时的替代、写操作只走待确认、回答反馈进评测集，全在同一个闭环里。危机处置需要有人接手：在只有你一个人的阶段，至少要做到信号实时通知到你，页面上展示核验过的求助信息，并停止一切催学。
- 阅读器需要有使用权的文本。自编讲义、官方公开的大纲与规范、已获授权的电子教材都可以。原型里“只映射”的纸书和“只外链”的网课在 5 期，不在这里。
