## 本期的关键判断（分期规划原文）

- 0 期交付的是确定性，而不是功能：一条能跑通的最细链路，加上几份写下来的结论。它的价值在于让 1 期开工时不再有未知数。0 期要短，超过 60 轮通常说明已经在做 1 期的事了。
- 种子考试怎么选。看三条：客观题占大头，因为主观题批改要到 6 期；你能合法使用它的知识点、题目与解析；近几个月能找到有真实考期的受邀用户，因为 3 期需要跨越一个真实考期。原型的四门演示考试里，初级会计职称最贴近这三条。另选一门评价规则不同的考试只做测试夹具（例如分数段型的英语六级），用来防止数据模型被一门考试带偏。
- 原型里的演示数据可以直接用。四门考试的章节、知识点、例题与逐选项解析、错题样例都在原型的脚本里，转成种子与测试夹具，能省掉 0.2e 的一半工作。
- 探针都是时间盒。到预算就停，写下“目前最好的结论”和“还不知道什么”。探针 C 的结论如果偏悲观，不影响 1–4 期，只影响 5 期“自建”路线的厚度。
