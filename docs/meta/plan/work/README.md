# 预写计划

本目录放闭环开工前预先写好的计划，供 P2 第 1 步直接使用（docs/meta/plan/README.md 第 3 节）。

- `<功能ID>.md`：功能的 work 文件预写稿。开功能分支并运行 `python scripts/spec_tool.py work start <ID>` 后，用本目录同名文件的“## 计划”一节整体替换 work/<ID>.md 的同名一节；front matter 以 work start 生成的为准。
- `<切片>.md`（如 0.1b.md）：闭环级任务的计划，由 Codex 直接执行，不走交接包。
- 写法：“改动文件”“参考文件”两项下每行只写一个路径，说明放在其后的中文括号里；以 / 结尾表示目录。仓库根下文件名含两个点的（如 vitest 与 playwright 的配置文件）写成 ./ 开头，交接脚本才能识别。
- 使用前核对：计划中的路径以闭环级任务实际交付的为准，不一致时先改计划再请产品负责人确认。
- 闭环收尾（P6）后，本闭环的预写稿删除；计划的历史以功能分支的提交为准。
