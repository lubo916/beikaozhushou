# 预写计划

本目录放网页版 Claude 预先写好的计划（ADR-030），由 handoff.py 随编写包送达，不由 Codex 起草。

- `<切片>.md`（如 0.1b.md）：闭环级任务的计划，随该闭环的规格批次编写（README 的 P1），由 Codex 在 `chore/<切片>-<短名>` 分支上执行，不走交接包；计划写明“定位判据”（主干上能机检的完成条件），drive 据此判断是否完成。
- `<功能ID>.md`：功能计划的预写稿（可选）。P2 开工时，Codex 先用 `python scripts/handoff.py adopt-plan <ID>` 把它换入 work 文件并按 review-plan 复核；复核不通过，再用 `write-plan <ID> --notes` 请网页版 Claude 按仓库现状改（计划包带着预写稿）。没有预写稿的功能，直接出计划编写包。
- 写法：“改动文件”“参考文件”两项下每行只写一个路径，说明放在其后的中文括号里；以 / 结尾表示目录。仓库根下文件名含两个点的（如 vitest 与 playwright 的配置文件）写成 ./ 开头，交接脚本才能识别。
- 闭环收尾（P6）时，删除本闭环已执行完的计划与预写稿；计划的历史以功能分支与 work 文件的提交为准。
