## 期末（P5-出）

出口标准：
- 自建或模板目标的两周留存可与官方目标比较
- 体检阻断项能拦住不合格地图
- 对齐审核的人工修正量在可接受范围

观测指标：
- 自建与模板目标的两周留存、体检通过率、对齐审核的人工修正率、导入失败率

旅程检查：本期结束时用户能走到哪：
- 首次使用／选目标：厚
- 首次使用／时间与资料：厚
- 一天／练习：厚
- 一个考期／考后与下一站：厚

风险巡检：
- AI 解析质量不够：重跑探针 C 的人工修正量仍很大 → 收缩为“模板＋手动”，自建降级。
- 数据模型被一门考试带偏：加第二门考试时要改表 → 5 期开工前做的模型审查要落实。

滚动细化：Codex 汇总本期 docs/product/calibration.yaml 算出系数，重估下一期预算，复核下一期各闭环的功能切分与规格种子，起草期复盘与下一期调整，交你确认。

## 本期的关键判断（分期规划原文）

- 通用化为什么在后面。闭环还不稳定时做通用化，每改一次闭环，都要同时改三种地图来源和十类资料；等闭环稳了再开放入口，改动面最小。数据模型在 0 期就是通用的（四类评价规则、九类知识类型、地图版本与扩展层），所以 5 期不是重写，而是“打开入口”。
- 探针 C 的结论决定 5.2–5.4 的厚度。AI 解析质量够好，就按原型做“生成或对齐”；质量一般，就把重心放在手动编辑（S09-08）与模板（5.7），自建降级为“骨架生成＋人工补全”。开工前用最新的模型把探针 C 再跑一次，成本很低。
- 体检是通用化的安全阀。自建与模板地图质量参差。5.5 的体检不通过时，锁住预测、性价比阶梯与分值地图，只锁数字，不锁学习。原型的原话是：地基不合格时给出的数字只会误导。
