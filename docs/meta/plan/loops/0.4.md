- **0.4A 探针 A：证据→档位规则**：用原型规则写成测试表，结论写入 OQ-002。
  - 验收：规则表里每一行都有一条通过的单元测试。
- **0.4B 探针 B：记忆调度选型**：在模拟数据上比较两三种调度（基线候选 ts-fsrs，ADR-025），结论写入 OQ-003。

  - 验收：给出准确率、人工修正量，以及“自建路线”继续或收缩的结论。
- **0.4D 探针 D：排程启发式**：配比、保底、顺延、提议的规则在模拟数据里不崩，结论写入 OQ-005。
  - 验收：用种子数据模拟八周，每日任务量不超时间预算。
