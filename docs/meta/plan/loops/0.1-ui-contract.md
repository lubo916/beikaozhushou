# 0.1 外壳令牌、样式与测试接口

本文属于尚待实施的 0.1b 前置；设计值已登记在 design/tokens.json 与 tokens.resolver.json。PLAT-01 组件实现只消费生成物，不自行补像素值或主题色。页面/组件类型另见 docs/domains/platform/PLAT-01-components.md。

## 来源与必需令牌

已有配色、字体、圆角及断点来自冻结原型。新增 space、size.shell、focus、border、layer、duration、ease、shadow 是本轮外壳工程初始值：尺寸覆盖三档导航、标题栏/底栏、抽屉/面板、图标与动作；留白取基础步进；焦点/边框确保可见；层级保持导航、遮罩、弹层、通知有序。深色和 cvd 颜色按下面对比度要求选择。它们是可修改的设计值，不是学习参数；实际值只读 JSON，本文不另列数值表。

0.1b 生成前验证必需键全部存在：color.bg.*、ink.*（含 on-brand）、line.strong/soft、brand.*、status.*、cvd.*；font.family/size/weight/line-height；radius；space.xs/sm/md/lg/xl/xxl；size.breakpoint.*、size.viewport.min、size.shell.sidebar/rail/header/bottom-nav/drawer/panel-max/content-max/icon/action-min；focus.width/offset、border.width、shadow.overlay、layer.base/navigation/backdrop/dialog/toast、duration.fast/normal、ease.standard。缺键、同名冲突、未解析别名或错误 DTCG 类型即生成失败，不插默认值。0.1 只构建 brand=platform；brand.org 依赖未来机构配置，构建输入先移除整个 org 上下文再调用令牌编译器，不把含未绑定别名的完整 resolver 交给编译器，也不用假机构值使其通过。

## 主题解析与 CSS 变量

合并顺序 scheme→brand→vision→text，各修饰器内覆盖基础值，完成合并后才解析别名。scheme=light/dark，vision=default/cvd，text=default/large；八种组合都编译验证。cvd 的 status 覆盖引用 color.cvd.*，后者随 scheme 变化，所以深色×cvd 不沿用浅色固定值。

外壳根带 data-ep-shell、data-scheme、data-vision、data-text，默认 light/default/default。所有组件、原生 dialog 及 portal 放在这个根下，继承同一组变量；不在 body 外单独建一套主题。生成 tokens.css 以 [data-ep-shell] 声明默认组合，以同根属性组合选择器覆盖最终值。变量路径按点转短横线、原短横线保留、统一前缀 --ep-；如 color.bg.canvas→--ep-color-bg-canvas。同名转换碰撞则失败。dimension 输出数值+单位，duration 输出 ms，shadow 输出标准 CSS shadow，别名不留在产物中。

## Tailwind 与容器查询

CSS 自定义变量不作为容器断点条件。0.1b 用登记值在构建期生成 tokens.theme.css 的静态 --container-tablet/desktop/content-md/content-lg，编译器据此产生容器查询；不在手写组件插像素条件。最外层是查询容器，布局元素在其内部，避免元素查询自身。

Tailwind 4 的 theme 命名空间决定工具类和容器变体；静态断点与运行时颜色分开生成。先清空默认主题 --*:initial（含调色板、间距及 viewport breakpoints），仅登记映射；--container-* 写入登记的静态 dimension，保留 --breakpoint-* 为空，手写界面不使用 viewport sm:/md: 变体。其余用顶层 @theme inline 连接运行时变量：color.*→--color-*，font.family→--font-*、font.size→--text-*、font.weight→--font-weight-*、line-height→--leading-*，space.*→--spacing-*，radius→--radius-*，shadow→--shadow-*，ease→--ease-*。图标/导航/焦点/层级/时长等未映射字段直接引用 --ep-*。尺寸使用登记名，不启用 p-4 这类隐式默认刻度。相关机制依据 [Tailwind theme 文档](https://tailwindcss.com/docs/theme) 与 [容器查询文档](https://tailwindcss.com/docs/responsive-design#container-queries)。

## 样式检查和可读性

0.1b/Codex 交付样式检查器及测试，接入 verify 的 lint；扫描 apps/learner/src/** 与 packages/ui/** 的 CSS、TS/TSX 内 style 和 className。排除 generated、测试和 *.fixture.*；生成 CSS 允许由令牌编译出字面值。基于已登记 TypeScript 编译器 AST 提取样式/静态类，CSS 声明扫描颜色和尺寸；不新增解析依赖。检查器须拒绝裸颜色（含 hex/rgb/hsl/oklch 与颜色名）、非登记的 px/rem/em 尺寸、Tailwind 任意值裸色/裸尺寸、旧默认色盘/数字间距、手写断点条件；允许任意值只引用已登记 --ep-*，发现未登记变量也失败。动态类拼装不能规避检查；只允许静态登记类名数组/映射，经提取后逐项检查。

白名单仅为结构语法：0、1、-1、100%、100dvh、1fr、auto、none、inherit、transparent、currentColor、normal，以及 min/max/clamp/calc 中这些结构量和登记变量。颜色关键字 transparent/currentColor 不承担信息对比。其他需要的非零设计量先入令牌；不能以 param-exempt 绕过样式检查。0.1b 的检查器用裸值/任意类/未登记var 的负例及登记变量/结构量的正例验收。

使用 color.line.strong 表示必要的控件边界，line.soft 仅作装饰；文字分别使用 ink、on-brand 或 status 前景与对应背景。普通文字按 4.5:1，必要控件边界/焦点按 3:1 校验，采用 [WCAG 2.2 对比度要求](https://www.w3.org/TR/WCAG22/#contrast-minimum) 与 [非文字对比度要求](https://www.w3.org/TR/WCAG22/#non-text-contrast)。不以测试通过宣称整个产品已获无障碍合规认证。

源色板测试 tests/tooling/test_design_tokens.py 验证八种主题的文字/语义色/控件配对；0.1b 再验证编译后的 CSS 变量与源一致，真实组件无错误前背景配对。PLAT-01 AC5 只对浅/深色做截图和键盘焦点验收，cvd/large 本期仅要求源/编译及变量消费成立，不实现外观偏好设置；额外视觉矩阵归 ACCT-09。
