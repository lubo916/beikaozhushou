## 功能与规格种子

### 0.3-1 PRAC-01 行走骨架：知识点页做一题到方格变色

`practice` · R1 · 依赖 PLAT-01、LRN-01、CONT-02 · 规格：draft · 涉及跨闭环依赖

规格种子（来自分期规划切片 0.3a、0.3b、0.3c；写规格时转成 R 与 AC；与契约、ADR、glossary 冲突时以后者为准）：
- **0.3a 知识点页最简版与“做一题”**
  - 目标：能从知识点进入一道种子题并提交。
  - 范围：知识点页最简版：名称、所属章节、当前档位。
  - 范围：“做一题”：从该知识点关联的种子题里取一道；提交答案。先只支持单选；没有把握度、没有解析。
  - 范围：接口与端到端测试。
  - 不改：证据规则（下一个切片）。
  - 验收：能从知识点进入一道种子题并提交。
- **0.3b 证据写入与档位按 v0 规则重算**
  - 目标：提交后证据表多一条，档位按规则变化。
  - 范围：提交答案时写一条证据（只追加），同时按 0.1f 的事件表写一条“作答”事件。
  - 范围：写入后按 v0 规则重算该知识点的档位。
  - 范围：先写测试表：做对、做错各一种情况下档位如何变化。
  - 不改：界面（除显示新档位外）。
  - 验收：提交后证据表多一条，档位按规则变化。
- **0.3c 方格全景最简版与黄金路径 0**
  - 目标：一条自动化测试走完“做一题 → 证据 → 档位 → 方格变色”。
  - 范围：方格全景最简版：每个知识点一格，颜色按档位（颜色取自 0.2d 的常量）。
  - 范围：在 tests/golden/ 写黄金路径测试 0：进入知识点 → 做一题 → 证据表多一条 → 档位变化 → 方格对应格子颜色变化；接进 CI，以后每次提交都跑。
  - 不改：规则与数据模型。
  - 验收：自动化测试走完整条链路并断言格子颜色。
