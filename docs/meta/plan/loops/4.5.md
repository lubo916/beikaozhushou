- **4.5a 员工登录与二次验证**（建议切片）
  - 验收：员工用工作邮箱＋密码＋动态验证码登录后台，与学员登录完全分开。
- **4.5b 员工账号安全基线**（建议切片）
  - 范围：先把规则写成测试表（每一行“输入→期望”是一条单元测试），我核对后再实现到全绿
  - 验收：连续失败锁定并按来源限频；同一员工只保留一个活跃会话；停用即全部会话失效；密码过期须先改密。
- **4.5d 操作审计、敏感操作分档与重验身份**（建议切片）　与 ACCT-08、PLAT-03 共用切片
  - 范围：先把规则写成测试表（每一行“输入→期望”是一条单元测试），我核对后再实现到全绿
  - 验收：所有写操作留痕可回溯；不可逆的经二级审批（双人复核只留给这一档），可回滚的保存前后快照；敏感操作前重验身份，验证服务不可用时一律拒绝。

人工把关：真机看：手机 375 与桌面 1280 按验收各走一遍（并入闭环收尾走查）；规则表逐行核对：业务确认时看决策表与原型说法是否一致（本功能最重要的把关）
