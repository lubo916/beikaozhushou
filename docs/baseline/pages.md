# 页面清单与路由

> 70 页，来自原型。路由是建议值（F01 可改，改了同时改 F05 的路由表）。带 `:参数` 的路由，开发时用 `demo` 代替，例如 `/kp/demo`。
> 视图用 `?view=<键>` 切换；七态用 `?state=loading|empty|error|offline|limited|insufficient` 强制显示（只在开发与测试时生效）。
> 功能点数量来自原型：P0 必做 / P1 增强 / P2 远期（P2 先不做）。看某页的完整说明：`python3 tools/bk.py spec <页ID>`。
