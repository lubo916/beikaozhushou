# 核心数据对象与一向门决定

> 后端任务与规则卡必读。这里只写“是什么、谁写、硬规则”，不写字段细节（字段以 packages/db/prisma/schema/ 为准，B01 建）。
> 来源：分期规划“一向门清单”、册1 的“必须先定的关键决策”、原型各页“数据读写”。F01 核对，B01 落地。

## 1 主链（先做什么不会返工）

考试画像 → 知识地图 → 题目 → 作答与证据 → 掌握档 → 到期队列与计划 → 今日清单

证据账本是全产品唯一的写入汇合点：练习、读后即测、回忆评分、模考、主观题批改都往这里写；档位、预测、错题毕业都从这里读。

## 2 核心对象（按领域）

| 领域 | 对象 | 要点 |
|---|---|---|
| account | 用户、会话、设备、游客身份、年龄段、授权与协议同意记录 | 游客也是用户（标记 guest），登录后合并；同意记录只追加 |
| org | 机构（租户）、成员、班级、学员对机构的逐项授权 | 业务表从第一天预留机构归属字段；授权按数据四类 |
| exam | 考试画像（评价规则类型、科目、题型分布、成熟度）、学员目标（目标分、考试日期、主次）、考试日历 | 一个学员可有多个目标 |
| map | 知识地图（带版本）、知识点（稳定 ID、版本、类型一至两个、考频、路径）、知识点关系（八类）、合并拆分映射 | 知识点 ID 永不复用；地图升级用映射表迁移学习记录 |
| content | 题目（题型、结构化内容、答案、解析、可信度四级、版本）、题目与知识点多对多、资料、段落锚点、标注、笔记、卡片 | 题目改动生成新版本；作答指向题目版本 |
| practice | 作答记录、练习会话、错题（四个状态）、模考、试卷快照、考试会话（服务器计时、断点） | 作答只追加 |
| learner | 证据、掌握档（系统判定、自评、目标、不确定度、待验证）、记忆状态（ts-fsrs）、复习记录 | 证据只追加，掌握档可从证据重算；只有本领域能写这两类表 |
| plan | 时间预算（周时间格）、计划（版本、轮次、学习范围三态）、任务（今日清单项）、重排记录、提议 | 提议是一等对象；重排记录只追加；时间预算可被多目标和机构任务共享 |
| metrics | 预测记录、指标快照 | 预测记录只追加，供事后校准 |
| billing | 档位、权益、订单、AI 点数流水 | 金额存整数分；点数流水只追加；扣减用带条件的原子更新 |
| aigov | AI 场景、调用记录（去标识）、提示词版本、评测结果 | 所有 AI 调用经 packages/ai/core |
| engagement / support | 通知、提醒订阅、工单、反馈、报错 | |
| compliance / platform | 参数注册表、功能开关、审计日志、导出与删除请求 | 审计只追加 |

## 3 一向门决定（走过去难回头，开工前定死）

| # | 决定 | 定法 |
|---|---|---|
| 1 | 证据的保存方式 | 只追加的事件：带来源、题目可信度、把握度、用时、时间；题目改答案后可撤回并重算 |
| 2 | 知识点身份 | 稳定 ID ＋ 版本号 ＋ 合并拆分映射；学习记录跟着映射走 |
| 3 | 题目可信度 | 四级（审定题、自有题、已确认的生成题、未确认的即时题），决定证据强度上限 |
| 4 | 数据分类 | 每张表、每类字段标四类之一（机构任务、个人学习、敏感、推断）；机构可见、导出、删除按类别处理 |
| 5 | 机构归属 | 业务表预留机构字段；数据访问层带“当前用户、当前机构”；接入第一家真实机构前给机构相关表开行级安全 |
| 6 | 游客 | 游客是正式用户的一种状态，登录后数据合并，不做迁移 |
| 7 | 提议 | 一等对象：改什么、为什么、代价、不改会怎样；来源（计划引擎、复盘、测评、导师）；状态（待确认、已确认、不改、已撤销） |
| 8 | 参数 | 所有阈值进参数注册表（名称、默认值、可调范围、谁能调）；代码经访问器读取 |
| 9 | AI 的位置 | 计划与调度不依赖大模型；AI 统一走网关（降级、标识、计量、评测在网关做） |
| 10 | 时间预算 | 独立对象，可被多目标与机构任务共享 |
| 11 | 客户端形态 | 响应式网页 + PWA 先行；以后 Capacitor 套壳；接口与领域代码不因端而变 |

## 4 硬规则

- 主键 UUIDv7（离线时客户端也能先生成）。
- 时间存 UTC；“今天”按用户时区算。默认凌晨 4 点切到新的一天、默认北京时间、用户可改（决策单第 6 条）；参数表已有设定的以已有为准。日界线是参数，所有跨天逻辑（今日清单、夜间顺延、连续天数、到期）共用一个“今天”函数，放 packages/shared。
- 只追加的表：作答、证据、复习记录、重排记录、预测记录、点数流水、同意记录、审计日志。
- 软删除配回收站；注销有冷静期（天数是参数）。
- 手机号加密存储 + 哈希查询；日志脱敏；接口字段白名单。
- 核心领域代码不出现考试 ID 判断。
