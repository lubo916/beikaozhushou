# 规则卡：证据与掌握档

- 状态：已定稿（2026-10-21，你已确认；再改需要你同意）
- 用在：S18-03、S18-04、S18-09、S18-10、S18-12、S18-16、S18-26；S10-01、S10-06、S10-08；S09-02、S09-03、S09-04、S09-09、S09-14
- 由谁执行：learner 领域的两段纯函数“证据定级”和“掌握档派生”（packages/domains/learner/core/，B04 实现）；做题、复习、批改只经接口交作答，不直接写证据和掌握档

## 目的

把每一次作答、复习、检验记成一条证据，再由证据算出每个知识点的掌握档（0–5 六档）、证据够不够、要不要换题复考，以及地图上的已学、已达标和掌握分布。同一份证据什么时候重算，结果都一样。

## 什么时候用

- 每交一次作答（练习四种模式、读后即测、片内检测、模考、摸底、自评检验）或每做一次复习评级时，定这条证据记什么。
- 学员确认或否认一道生成题时。
- 证据被撤回（题目事后改了答案）、地图拆分合并、规则版本变化时，重算受影响的知识点。
- 页面要显示阶梯、方格、地图上的数、“需要你注意”时，读这里算好的结果；页面不自己算（红线 5）。

## 输入

1. 证据账本（只追加）：来源、知识点、题目和版本、题目可信度、对错、把握度、用时、提示用了几级、作答时间、写入先后；撤回事件指向被撤回的那条。
2. 题目信息（内容领域给）：题型、建议用时（题目自带或题型默认，可能没有）、关联的知识点。生成题另带四项：是否先做后核、学员点了“题目没问题”“有问题”还是没点、机器质检是否通过、是否找到出处。
3. 知识点信息（地图领域给）：知识类型一至两个、地图上单独设的目标档、是否在学习范围内、是否章节目录、是否已退役、拆分合并映射。
4. 学员设置：把握度是否关闭、个人改的目标档、自评档。
5. 参数：见“参数”。

## 输出

- 每条证据：强度（强、中、弱、负、待验证，或“不记”）和原因代码（见 R1–R5）。S18 揭晓第一句“这次记为什么证据”、S10“档位是怎么算出来的”都用它。
- 每人每个知识点一行掌握档：系统判定（0–5）、分数档（R9）、累计分、证据是否充分、是否待验证、目标档及来源、差几档、规则版本；档位变化时发 mastery.changed。
- 地图上的数：已学、已达标、范围内、地图总数；掌握分布；“需要你注意”的证据不足数、待验证数；“薄弱”名单。
- 页面这样显示：S10 阶梯同时标系统判定、自评、目标档，写“还差 N 档”或“已达标”，证据不足时注明；S09 方格见 R19。文案里出现的规则数字一律用参数插值。

## 规则（大白话）

### 一、每条证据记什么

R1 不记证据：在场时长、只看只读、自习室专注、手动勾“看过”；摸底时选“不会”（dont_know）；复习评级用时短于 learner.memory.min_rating_seconds（rating_too_fast）；复习时选“忘了”（forgot；遗忘交给记忆状态，不扣掌握档）；生成题学员没点“题目没问题”（generated_unconfirmed；点了“有问题”的同时进入报错）。

R2 作答按下表从上往下找，命中第一行就停：

| 作答情况 | 记为 | 原因代码 |
|---|---|---|
| 答错（不论把握度、提示、用时） | 负 | wrong |
| 答对，把握度是“蒙的” | 待验证 | guess |
| 答对，用时 < 建议用时 × learner.evidence.fast_answer_ratio（秒答；题目没有建议用时就跳过这一行） | 待验证 | fast |
| 答对，把握度是“确定” | 强 | normal |
| 答对，把握度是“模糊” | 中 | vague |
| 答对，把握度已关闭 | 先当“确定”算，到 R3 最后一步压到中 | confidence_off |

R3 再依次往下压、不往上抬：① 用过提示（任一级）最高记弱（hint）；② 按题目可信度封顶（learner.evidence.credibility_caps）：一级审定、二级自有最高强，三级已确认的生成题最高中，三级题同时满足“先做后核确认过、机器质检通过、找到出处”时最高强（credibility_cap）；③ 把握度关闭的最高中（confidence_off）。负和待验证不受影响。原因代码写最后一个真正把强度压下来的那条。

R4 生成题（先做后核）：揭晓前可信度标“待你确认”；学员点“题目没问题”后按三级算；没点或点“有问题”不记。先看了答案再存进题库的（先看后存）按三级算、最高中。

R5 其他来源：复习评级选“忘了”以外的三档，记弱（recall）。一道题关联了几个知识点，就给每个点各记一条同样的证据。主观题由批改给出对错后照 R2、R3 记；学员给自己判分的最高记弱（self_graded；临时，等主观题批改规则）。

### 二、待验证

R6 待验证只记录、不计分。作答满 learner.verify.recheck_after_hours 小时后，同一知识点换一道题复考（作为“待验证复核”进今日巩固段，怎么排归 R04）。复考按 R1–R5 正常记；原来那条一直不计分、不补记。

R7 知识点的“待验证”标记：还有待验证证据没被复考过，就显示“待验证”。复考＝之后作答的另一道题，且作答时间不早于等待时长到期的时刻；不论对错都算做完。同一道题再做、或时长没到就做别的题，照常记证据但不算复考；复考又蒙对或秒答，产生新的待验证。

### 三、从证据算出档位

R8 累计分：按写入账本的先后，把强、中、弱、负证据的权重（learner.evidence.strength_weights）逐条相加；待验证、已撤回的不算；每加一条，低于 0 就按 0 算（早期做错不欠分）。

R9 先定“分数档”：累计分过了几道门槛（learner.mastery.level_thresholds，五道门槛对应 1–5 档）就升到几档，降档按 R14；再按 R10、R11 卡上限，按 R13 托下限，得到系统判定。分数档和累计分一起存，增量计算要用。

R10 到 3 档“已掌握”及以上，至少要有 learner.mastery.cross_check_items 道不同的题记过强证据（异题印证；同一道题的不同版本算一道），不够最多 2 档。把握度关闭时，只因关闭才记成中的证据（原因代码 confidence_off）在这里和 R11、R17 都当强证据算，计分仍按中，所以要多做几道（R01-Q7 已拍板：B）。因此只靠复习卡片、只有“模糊”的中证据、同一道题反复做对，都到不了 3 档；只凭生成题时也要另一道题印证。

R11 到 4 档“能应用”，至少一道应用类题记过强证据，不够最多 3 档；到 5 档“能迁移”，至少一道综合题记过强证据，不够最多 4 档（把握度关闭时同 R10）。应用类题按题型认（learner.mastery.apply_question_types：材料题、计算与分步、简答、论述写作、口头作答、实操提交）；综合题是同时关联 learner.mastery.transfer_min_kps 个及以上知识点的应用类题，或题目单独标了“迁移”（R01-Q1 已拍板：C）。

R12 自评检验通过的那一刻，累计分补到第 3 道门槛（见 R17）。

R13 只要有过强、中、弱、负证据，档位最低 1 档“已了解”；0 档“未学”只留给没有这些证据的知识点（R01-Q2 已拍板：B）。

R14 档位随累计分升降：升档过门槛就升；降档要多跌一点——累计分比当前分数档的门槛还低 learner.mastery.drop_buffer 分才降一档，跌得多可以连降，但不低于 R13 的下限（R01-Q4 已拍板：B）。撤回后从头重算，缓冲不会把撤回前的档位留住。遗忘风险由记忆状态单独表达（R02），不自动降低掌握档。

### 四、证据够不够

R15 证据充分：强、中、弱、负证据来自至少 learner.evidence.min_for_sufficient 个不同的题或卡片（同一道题的不同版本算一个，同一张卡算一个；待验证不算）。不够就是“证据不足”：方格画虚线，不等于“不会”，也不算“已达标”。

R16 拆分与合并：拆分后，原来的证据按映射算进每个新点（不清零），但新点攒够 learner.evidence.min_for_sufficient 个自己的不同题目或卡片之前，一律“证据不足”；合并后，几个点的证据合在一起重算。映射细节归地图版本任务（S09-14）。

### 五、自评与检验

R17 自评只显示，不直接改档。自评在 3 档及以上、又高于系统判定时，随即出 learner.self_check.items 道检验题（来源 self_check，按 R1–R5 记）。通过＝这几道都答对，而且都是 R10 说的强证据（把握度关闭时只因关闭才记成中的也算）。通过后系统判定至少 3 档（仍要满足 R10），以后做错照常扣分；没通过或没做完，检验题照常计分，自评只显示（R01-Q3 已拍板：B）。

### 六、目标档与地图上的数

R18 目标档按顺序取第一个有的：个人改的 → 地图上这个点单独设的 → 按知识类型的默认（learner.mastery.default_target_by_type）。标两种类型取高的；只标积累拓展型的不设目标档、不进方格；没标类型的按参数里“没标类型”一项（默认 3），地图体检提示去补。差几档＝目标档 − 系统判定（R01-Q5 已拍板：A）。

R19 地图上的数只算知识点（不含章节目录、已退役的点、只标积累拓展型的点）：
- 已学＝有过任一条未撤回证据（含待验证、负）的点数 ÷ 地图知识点总数（含范围外）。
- 已达标＝学习范围内、证据充分、系统判定 ≥ 目标档的点数 ÷ 学习范围内的点数。
- 掌握分布＝学习范围内按“未学、证据不足、1–5 档”分别计数；“需要你注意”＝学习范围内证据不足的个数、待验证的个数。
- 方格按顺序取第一个命中的：范围外斜纹 → 没有任何证据灰色“未学” → 证据不足虚线 → 其余按系统判定着色。

R20 “薄弱”筛选：学习范围内、证据充分、系统判定比目标档低 learner.mastery.weak_gap_levels 档及以上（R01-Q6 已拍板：A）。

### 七、撤回、重算与写权限

R21 题目事后改了答案、或生成题事后被判有问题，由它产生的证据写撤回事件，受影响的知识点从头重算（S18-26）。新证据追加在末尾、增量算；撤回、地图映射、规则版本变化时从头算。都按写入账本的先后排序，从头算和增量算结果一样。

R22 系统判定只由本卡规则算、只由 learner 领域写；导师（AI）不估档、不改档，只能提议（红线 3）。摸底估计（R05）不直接写系统判定，也不会让已有证据算出的档位下降。

## 不做

- 主观题怎么判对错、导师批改要不要学员确认：归主观题批改的规则；本卡只接收批改给出的对错（R5）。
- 摸底估计和起点报告（R05）；记忆状态、遗忘风险、复习排程（R02）；错题回炉与毕业（R03）；复考任务怎么排进今日（R04）；预测与三个数（R06）。
- 一道题挂多个知识点时按错因只扣出错的那个点：现在一律每个点各记一条。
- 证据随时间变旧而减分、按同类考生推算起点：都不做。
- 自评检验多久能发起一次、检验题和复考题怎么挑：归做题与内容任务。
- 页面文案：各页任务按原因代码和参数写。
- 参数表、口径表、勘误表、词汇表的改动：不在本任务范围，见交接单，由整合任务处理。
