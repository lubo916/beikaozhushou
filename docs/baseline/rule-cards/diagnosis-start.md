# 规则卡：摸底与起点报告

- 状态：已定稿（2026-10-21，你已确认；再改需要你同意）
- 用在：S04-01 至 S04-14；S05-01 至 S05-13（S05-14 是 P2，不做）。
- 由谁执行：learner 领域（选题与停止、起点估计、把握度校准、预测区间、差额归因、薄弱章节）；plan 领域（时间够不够、学习范围初稿、三档方案、生成计划、轮次草案）；practice 领域（诊断会话、断点、作答记录）；map 领域只提供地图体检结果。都写成纯函数放各领域 core/，页面只显示接口返回的数（红线 5）。
- 相关卡：证据与掌握档（R01）、记忆调度（R02）、计划与今日（R04）、三个数与统计口径（R06），都已定稿。用到它们的地方写“按 R0x”，本卡不替它们定规则；S05 上和 S24、S06 同名的数（区间、最可能值、置信程度、差额）一律按 R06 算。和它们还没同步的几处见文末“跨卡待整合”。

## 目的

用尽量少的时间估出整张地图的掌握分布，并在起点报告里回答四件事：现在在哪、差多少、差在哪、时间够不够；最后给三档方案，由学员自己选。本卡规定摸底怎么选方式和题、作答怎么计、什么时候停，以及起点报告里每个数怎么来、什么时候不给。

## 什么时候用

- 新学员入门第 4 步做摸底诊断（S04），第 5 步看起点报告并生成计划（S05）；从知识地图（S09）或起点报告进来再次诊断、补测几章；断连回来做补充诊断（R18）；修好地图、复检通过后恢复预测（R23）。

## 规则

### 一、选方式与题源（S04-01、02、03、06、09）

R1 摸底只用一级审定题和二级自有题；三、四级生成题不进摸底。

R2 三种方式什么时候能用：自适应诊断要求带难度标定的审定题不少于 learner.diagnosis.adaptive_min_pool 道；章节抽测要求一、二级题合计不少于 learner.diagnosis.min_pool_items 道，每章抽 learner.diagnosis.chapter_items 道（下限到上限），先审定题后自有题，优先中等难度的客观题，同章尽量不同知识点；快速定位不需要题，总是能用。

R3 默认选中：自适应能用就默认它（不标“推荐”）；不能用时默认章节抽测并标“推荐”（自建地图常见）；一、二级题合计不足 learner.diagnosis.min_pool_items 道时，S04 进入“空”态：只能快速定位，按钮“改用快速定位”，并提示可以先导入题目。

R4 开始页的“约 N 题、M 分钟”和测评条的“约 N 题、预计剩余”都由接口算好下发：自适应的 N 默认取题量上下限的中间值（向上取整），测评中改为“已答题数加预计还要答的题数”；M 按题目平均建议用时折算。原型的“约 26 题、15 分钟”只是示例。测评中换方式只留“改用快速定位”一个入口。

### 二、作答怎么计（S04-04、05、07、10、11、13）

R5 测评态：全程不显示对错和解析，不出现导师、搜题、提示与推送。

R6 每题必须在“确定、模糊、蒙的、不会”里选一项才能提交，不设默认。选“不会”可以不选答案；选了答案也按“不会”算。

R7 每题从上往下取第一条命中的。“起点估计里算”只决定估计；“证据”交给 R01 按它的证据表记：

| 作答 | 起点估计里算 | 证据（按 R01） |
|---|---|---|
| 选“不会” | 不会（与做错同等，不额外扣） | 不写（已拍板：R05-Q2=A） |
| 做错（任何把握度） | 做错 | 不写（已拍板：R05-Q2=A） |
| 选“蒙的”且做对 | 蒙对不算会，按做错算 | 待验证 |
| 做对，但用时低于建议用时 × learner.evidence.fast_answer_ratio（秒答） | 会 | 待验证 |
| 选“确定”且做对 | 会 | 强（不超过题目可信度上限） |
| 选“模糊”且做对 | 会 | 中 |

把握度校准按确定、模糊、蒙的分别累计作答数和做对数，“不会”单独计次。

R8 随时可以“暂停并退出”：已答的题保留、不过期，回来接着做，不重做已答题。已下载的题可以离线作答，联网后提交；中途断网不丢答案。

R9 中途“改用快速定位”：已答的题保留并照常计入；没测到的章节改成按章自评；报告按实际依据出（R20、R22）。

R10 快速定位：每章自评一次，没学过、学过但不熟、基本会、很熟练分别对应自评档 0、1、2、3，不确定度取 learner.diagnosis.self_rating_uncertainty。有可用题时再出核对题：一共最多 learner.diagnosis.quick_check_items 道，每章最多 1 道，按自评档从高到低选章（相同按地图里的章节顺序），没有可用题的章跳过，章不够时核对题就少于这个数。本章核对题做错（含蒙对，按 R7）或选“不会”，本章按自评档减 1 算，但最低是 0 档：自评“没学过”的章核对答错或选“不会”仍是 0，任何情况都不出现负档；做对不往上抬；每章只核对 1 道，所以一章最多降一档。本章的点按 R15 ③ 取这个档（这些章的模块估计就取这个档，不确定度不变）；核对题测到的那个点是真实作答，按 R15 ① 算，核对题本身照 R7 记证据。按章自评只进起点估计，不写证据、不改系统判定。

R11 主观题（P1）：先作答，或至少思考 learner.diagnosis.subjective_min_seconds 秒，才出现得分点清单；对照勾选的结果只进起点估计，不写证据。

R12 诊断里做错的题不自动进错题本；交卷后可以在“诊断错题”清单里看对错和解析，手动勾选加入。原型没画这个清单放在哪，由页面任务定。

### 三、自适应什么时候停（S04-01）

R13 每答一题，按当前估计挑下一题的模块和难度（估计和选题方法由 B08 实现）。满足任一条就结束：① 已答题数不少于 learner.diagnosis.min_items，并且每个已测模块的不确定度都不超过 learner.diagnosis.stop_uncertainty；② 已答题数达到 learner.diagnosis.max_items；③ 学员改用快速定位或主动结束。没到下限前即使精度已够也继续出题。

### 四、起点估计（S04-08、12、14；已拍板：R05-Q1=A）

R14 每个测过的模块给出能力估计（用掌握档 0–5 作刻度，可带小数）和不确定度（正负几档）。

R15 每个知识点的起点估计，按依据从上往下取第一个有的：
① 本题测到：算“会”的，估计档 = 模块估计向上取整，且不低于 learner.diagnosis.correct_min_level；算“做错”的，估计档 = 模块估计向下取整，且不高于 learner.diagnosis.wrong_max_level；选“不会”的为 0。
② 所在模块测过：估计档 = 模块估计四舍五入，不确定度加大。
③ 所在章做过按章自评：按 R10。
④ 同类人数不少于 learner.prior.min_population：用群体先验，标“按同类考生估计”。
⑤ 都没有：无依据。方格画虚线格；依据里写“有 N 个模块没有依据”。预测不看本条，照 R19（证据不足的点按 R06 R7 代替）。

R16 起点估计、系统判定、当前档是三样东西，分开存、按固定先后显示（已拍板：R05-Q1=A）：
① 起点估计：learner 领域掌握档对象里的估计字段（估计档 0–5、不确定度、依据），只由摸底写（R10、R15、R17），不是证据。
② 系统判定：只由证据按 R01 算、只由 learner 领域写；摸底只经 R7 给它供证据（做对的题），从不拿起点估计去写它，也不让它下降。
③ 当前档：不单独存，每次从前两样里取：证据充足 → 系统判定（起点估计更高也一样）；证据不足、有起点估计 → 起点估计，标“估计”；证据不足、也没有起点估计 → 虚线格。下文的“当前档”都指 ③，只用在本卡自己的显示和估算：方格（R28）、差距归类（R24）、薄弱章节（R27）、需要时间（R29）。跨页统一的预测不用它：区间、最可能值、置信程度、差额、潜在提分都按 R06 取输入（系统判定；证据不足时按 R06 R7 换成同类考生平均得分率或本人系统判定档），起点估计再高也不替换（E42）。计划引擎排任务按 R04（补到目标看系统判定，R04 R7），本卡不替它定。

R17 再次诊断只升不降，只动起点估计：只更新本次测到的点（本次直接作答过的点），新的起点估计取原起点估计和本次估计中较高的那个（相同时用本次的；不确定度和依据跟着一起换），原来没有就用本次的；没测到的点不变。系统判定照 R16 ② 不被改写：做对的题按 R7 写证据，由 R01 重算；做错和“不会”不写负证据，所以系统判定不会因摸底下降，这些点交给记忆调度（按 R02）安排复习。最后按 R16 ③ 重新取当前档：证据充足的点即使新的起点估计更高，也显示系统判定（E40）；某点因本次新证据变得充足时，当前档改为显示系统判定，这是换了显示来源，不是摸底把档拉低。

R18 补充诊断：断连天数达到 plan.disconnect.tiers_days 的高档（默认 14 天）后回来，可以选做一次补充诊断：共 learner.diagnosis.refresh_items 道题，只从当前档为“已掌握”及以上的点里抽，遗忘风险高的先抽；结果按 R17。

### 五、现在在哪、差多少（S05-01、10、12）

R19 英雄区的区间和最可能值就是 R06 的“按今天的水平”（R06 R6–R8、R10a）：S05 和 S24、S06 同一来源，本卡不另算，不拿模块不确定度、起点估计或覆盖率目标去合成（覆盖率目标按 R06 R14 只用来监控）。只给保守到乐观的区间和最可能值。英雄区同时写目标线；考试画像有合格线才写合格线（分数段型等没有就不写）。

R20 置信程度按 R06 R11：（乐观 − 保守）÷ 满分不超过 6% 为“高”，不超过 12% 为“中”，否则为“低”（参数 learner.forecast.confidence_width_ratio，和 R06 同一个）。比值用 R06 R8 取整后的区间端点直接算，比值本身不四舍五入：正好 6%、12% 算在分界以内，43 ÷ 710 约 6.06% 是“中”，不当成 6%（E19、E41）。依据写清证据量（如“摸底 26 题”“快速定位”“摸底 12 题加按章自评”）、是否用了同类考生数据，以及 R06 R11 的按估计代替的分值占比。

R21 差额按 R06 R9：目标分 − 最可能值（取整后）；不大于 0 时不显示负数，写“按今天的水平，已过目标线”。

R22 只做了快速定位态（已拍板：R05-Q10=A）：有模块只靠按章自评（没有任何作答）时，S05 按“只做了快速定位”显示（页面状态“数据不足”）：区间和置信程度照 R19、R20，不另算；置信程度后写“区间更宽”，顶部写“约 X% 的分值是按估计算的；补做 K 章章节抽测（约 M 分钟）可以让起点估计更准”。X 是 R06 R11 的按估计代替的分值占比；K 章取只靠自评的章里、按 R06 R7 的上下沿算对区间宽度贡献最大的前 learner.diagnosis.suggest_chapters 章；M = 这几章抽测的预计用时之和。不写“比完整诊断宽约 N 分”，也不说补测后区间会收窄：按 R06，知识点证据充分后区间才收窄，每章补 2–3 题通常做不到。

R23 地图体检不通过（有阻断项，门槛见 map.health.*）：
- 不给预测：区间、最可能值、差额、可提分、方案卡里的区间与分数变化、范围提议里的“少拿约几分”都不出；英雄区写“地图体检还没通过，先不给预测分；掌握分布和学习安排照常给出”。
- 给逐项修复清单：每项写现状、门槛和“至少还要修几个”。下限类：门槛 × 总数向上取整 − 现有数；上限类：现有数 − 门槛 × 总数向下取整。
- 照常给：方格、薄弱章节、时间够不够、三档方案（只写每周时长和到目标日预计完成）、轮次草案。修完自动复检；通过后立即恢复预测，置信程度照 R20，不另外强标“低置信”。

### 六、差在哪（S05-02、03、04）

R24 差距归因：学习范围内、系统判定低于目标档的点（和差额、R25 的潜在提分同一批，按 R06），从上往下取第一条归类：① 性价比阶梯 D 级 → 低频冷门；② 本次测到且算作做错（含蒙对），或所在章自评为“学过但不熟” → 学过已忘；③ 当前档为 0 或没有依据 → 未学的高频点（D 级已在 ① 排除，这里的“高频”是相对 D 级说的）；④ 其余 → 会但不稳（含起点估计已到目标档、证据还不足的点）。

R25 可提分（已拍板：R05-Q8=A）：潜在提分和差额用同一套预测输入（按 R06，不用起点估计）：每个点算它补到目标档时最可能值多出的分（同 R06 R10b 的情景），按类相加得到“潜在提分”。
- 差额大于 0、潜在提分合计不少于差额：把差额按各类潜在提分的比例分摊，四舍五入；合计和差额不等时，把差记到潜在提分最大的一类（并列时按未学的高频点、学过已忘、会但不稳、低频冷门的顺序）。四项合计正好等于差额。
- 差额大于 0、潜在提分合计少于差额：不放大，直接显示各类潜在提分，另写“全部补到目标档也还差约 X 分”。
- 差额不大于 0：不分摊，显示各类潜在提分，表头写“已过目标线，还能再提的分”。
- 每类同时给所需时间（按 R04）和性价比（潜在提分 ÷ 所需时间），页面任务决定是否显示。行的顺序按可提分从大到小，低频冷门固定在最后。

R26 一句解读：按可提分最大的一类套固定句式，如“差距主要来自还没学过的高频点，而不是能力问题。”；差额不大于 0 用“已过目标线”的句式；体检不通过用 R23 的句式。句式放文案文件，数字用插值，不用词汇表第 11 节的慎用词，不交给大模型自由发挥。

R27 薄弱章节：每章给达标比例 = 本章学习范围内当前档不低于目标档的点数 ÷ 本章学习范围内的点数（分母不含范围外，同统计口径“已达标”）；未学数 = 本章学习范围内当前档为 0 的点数；本章考情级平均值（没有考情数据时用重要度）不低于 learner.report.high_freq_level 的标“高频”。按达标比例从低到高排，相同时按地图里的章节顺序。

R28 方格：每格一个知识点，按 R16 显示；学习范围以外的点画斜纹，无依据的点画虚线格；每章右侧写“达标数/本章学习范围内的点数”。

### 七、时间够不够与学习范围初稿（S05-05、06；已拍板：R05-Q5=A）

R29 需要时间 = 学习范围内各点从当前档提到目标档的预计学习时长之和（工作量按 R04）。

R30 可投入时间：从今天（按“今天”函数）到目标日前一天逐天算，每天可用 = 当天预算 − 当天机构占用，小于 0 按 0（同 R04 R1：被机构占满或占用超出的那天是 0，不是负数）；不可学日记 0（R04 R27）。逐天加总后乘（1 − plan.week.buffer_ratio），缓冲只扣这一次（同 R04 R11）。不能先把一周的预算和机构占用各自加总再相减：某天超出的占用会吃掉别的天（E44）。

R31 差 = 可投入 − 需要。“到目标日预计完成”时间卡和方案卡通用，不再叫“覆盖率”（已拍板：R05-Q6=A）；小时数和百分比都先算后取整（四舍五入）。按下面的先后取第一条命中的，任何情况都不除以 0，不出现 NaN 或无穷大：
① 需要为 0（学习范围内没有要提到目标档的点）：预计完成 100%；写“余量 X 小时”（X = 可投入，可以是 0），不写百分比；不给三条出路、不出范围提议、不提示填时间。
② 需要大于 0、可投入为 0：预计完成 0%；写“缺口 X 小时，约 100%”（X = 需要）；提示先去填时间，给三条出路；不出范围提议（没有可学时间，缩小范围也补不上）。
③ 其余：差小于 0 写“缺口 X 小时，约 Y%”，差不小于 0 写“余量 X 小时，约 Y%”，Y = X ÷ 需要；预计完成 = 可投入 ÷ 需要，最多 100%；有缺口时才给三条出路：加时间、缩小学习范围、调目标。

R32 学习范围初稿：默认范围 = 有目标档的知识点（跟随默认），没有目标档的点在范围外。有缺口且可投入大于 0 时（R31 ③）出一张提议：只从性价比 D 级的点里挑，从“每小时提分”最低的挑起，累计省下的时间达到缺口就停；D 级挑完还不够，就建议移出全部 D 级，并写明剩下的缺口靠另外两条出路。四行：改什么（建议先不学 N 个 D 级知识点）、为什么（它们考得少、学起来慢）、代价（少拿约 X 分，省下约 Y 小时；X 是这些点的潜在提分之和）、不改会怎样（这 Y 小时要从练习里挤）。按钮只有“确认”和“不改”；确认后这些点变成“我移出”，不删数据、仍可学。没有缺口时不出这张提议。差距表里“低频冷门”的数是分摊后的，和这里的 X 口径不同，不必相等。

### 八、三档方案与生成计划（S05-07、08、09、11、13；已拍板：R05-Q3=B、R05-Q4=A）

R33 每周时长（S = 学员声明的每周可学时间，d = plan.option.min_step_hours；稳妥、冲刺都取整到小时，已拍板：R05-Q3=B）：标准 = S。稳妥 = S × plan.option.steady_ratio 四舍五入，再压到不超过 S − d 向下取整；结果小于 d 小时就不出稳妥卡，因为“至少比标准少 d 小时”和“不少于 d 小时”做不到同时满足（S 小于 2d 时总是这样，比如 d 为 1、S 为 0.5 或 1）。冲刺 = S × plan.option.intensive_ratio 四舍五入，再抬到不少于 S + d 向上取整，冲刺卡总是有。所以展示出来的档一定是 稳妥 ≤ S − d < 标准 < S + d ≤ 冲刺，不倒挂、不重复（E25、E38、E39）。S 为 0（还没填每周可学时间）时不出方案卡，“生成我的计划”先引导去填时间，填完重算（R31 ②）。
“约每天” = 每周小时 × 60 ÷ 7，取整到分钟。界面档名用“稳妥、标准、冲刺”，代码用 steady、standard、intensive（已拍板：R05-Q7=A）。

R34 每档到目标日预计完成：需要为 0 时每档都是 100%（同 R31 ①）；否则 = 该档可投入 ÷ 需要，最多 100%。该档可投入照 R30 重新逐天算，只把每天预算换成“声明的当天预算 × 该档每周时长 ÷ S”（R37 的调法，不取整）；机构占用不跟着方案变，不可学日、0 下限和一次缓冲照旧。标准档就是 R30 的可投入；不能用“标准可投入 × 时长比”，那样会把机构占用也一起放大缩小（E43）。S 为 0 时不出方案卡（R33），所以不会除以 0。该档可投入大于需要（有余量）时写“留出 N 次模考”：N = 余量 ÷（考试时长 × plan.option.mock_hours_factor）向下取整，最多 plan.option.mock_cap 次；N 为 0、或考试画像没有考试时长时不写。

R35 每档给“到目标日”的预测区间，按各档自己的每周时长算，输入和 R19 一样、不用起点估计（已拍板：R05-Q11=A：这个算法由规则卡任务补进 R06，见跨卡待整合第 3 项；补好前例子里各档的最可能值和区间宽度是给定输入）。有稳妥卡时，标准和冲刺卡写“比稳妥多几小时 / 周，区间上移约几分”，上移 = 该档最可能值 − 稳妥最可能值，取整。没有稳妥卡时（R33），冲刺卡改写“比标准多几小时 / 周，区间上移约几分”，上移 = 冲刺最可能值 − 标准最可能值，取整；标准卡不写这一行（已拍板：R05-Q9=A）。代价只写在稳妥卡上：取整后的预计完成比标准低时写“到目标日预计完成最低”，它的区间确实最宽时再加“区间最宽”，两条都不成立就不写；没有稳妥卡就没有代价这一行。体检不通过时不写区间和分数。

R36 推荐（已拍板：R05-Q4=A）：固定推荐“标准”。标准到不了 100% 时，靠时间卡的三条出路和范围提议补，不改推荐。

R37 生成计划：学员选一档（没选就用推荐档）点“生成我的计划”。游客这时才要求登录，登录后游客的目标、摸底结果与学习记录并入账号（ADR-012）。计划引擎按所选档生成轮次路线和第一周日计划，附一段固定句式的说明。所选档和声明时间不同时，按比例调整周时间格里每天的时长（机构占用不变，R34），作为计划参数保存，之后可在学习计划里改。

R38 轮次草案（P1）：由计划引擎按目标日倒推（怎么切归 R04）；第一轮从今天开始，不显示已经过去的日期，时间短时从哪一轮起步也由 R04 定。只用路线名（打基础、攻重点、刷题冲刺、考前七天，或考试模板自带的路线名），不写“基础期、强化期”这类叫法（勘误第 12 条）。每轮写起止日期、目标深度（掌握档名称）和学法配比。生成计划前只是展示，不写进计划。

### 九、页面状态

R39 S04：可用题不足 → 空（R3）；测评中 → 受限（R5）；有模块要用同类数据代替 → 数据不足提示（R15 ④）。S05：一次摸底都没做完（含快速定位）→ 空，按钮“去摸底”；离线 → 显示上次的报告，重新生成要联网；游客 → 照常看报告，生成计划时才要求登录（R37）；只做了快速定位 → 数据不足（R22）；体检不通过 → 预测类区块锁定（R23）。
