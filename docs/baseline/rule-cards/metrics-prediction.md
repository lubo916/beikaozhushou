# 规则卡：三个数与统计口径

- 状态：草稿（R06 第 2 轮。R06-Q1～Q6 已按你的拍板写入，见 docs/decisions/D-2026-10-21-R06.md；R06-Q7、R06-Q8 待拍板，先按推荐写）
- 用在：S06-12、S06-17；S24-01、02、03、06、07、08、11、17；S08-02、S08-12 和 S08 的空态、数据不足态；S05、S07、S12、S17、S19、S23、S34 上出现的同名数字也按本卡
- 由谁执行：B11 实现。预测与差额、有效学习时长写成纯函数放 learner 领域 core；完成度、健康度、周报门槛放 plan 领域 core；正确率放 practice 领域 core；预测记录与指标快照由 metrics 领域保存（只追加）。页面、导师、周报文案只读接口结果。

## 目的

今日页常驻三个数，各答一问、不互相代替：够不够（预测与差额）、走了多远（完成度）、来不来得及（健康度）。另有三个数常和它们一起出现：投入了多少（有效学习时长）、学了几天（有效学习日）、做得对不对（正确率）。本卡把算法定死：同一个数在所有页面算法相同、叫法相同，例子表直接当测试。

## 什么时候用

- 打开 S06 今日、S24 进度与预测时：取三个数（R4–R22）。
- 有新证据、证据撤回、学习范围或目标档变了、地图升级、跨过日界线时：重算；预测变了就追加一条预测记录（R14）。
- S24“有效与在场”、S08 周报、S34 成长档案：取有效学习时长和有效学习日（R23–R27）。
- S17、S19、S23 显示正确率时（R28–R30）。
- 生成周报前：判断给不给结论（R31、R32）。

## 输入

- 掌握档（learner，按 R01 算）：每个知识点的系统判定档、证据是否充分；目标档。自评档不用。
- 知识点（map）：类型（积累拓展型不进三个数）、重要度、所属科目；考情的预期分值和数据成熟度；地图体检结果。
- 学习范围（plan）：跟随默认、我加入、我移出；时间预算（周时间格每天几分钟）；学员标的不可学日。
- 目标与考试（exam）：目标分、目标日；满分、评价规则（是不是每科都要过）、科目顺序。
- 同类考生数据（learner）：每个知识点的人数和平均得分率。
- 学习活动：类型、对象（哪一节、哪个会话）、设备、页面在前台且有操作（或正在播放）的时间段。证据账本（learner，只追加）：时间、是否撤回、是否计入。
- 作答记录（practice，只追加）：题目编号、时间、对错、题目可信度、是否撤回、是否主观题。预测记录（metrics，只追加）。
- 参数：见“参数”一节。

## 输出

- 预测：按今天的水平、按计划学到目标日各一组（保守、最可能、乐观）；差额或“已过目标线”；置信度高、中、低；权重依据和“按重要度估算”标注；被估计代替的分值占比；较上周；锁定原因。追加预测记录。
- 完成度：已到手的档、总档数、百分比；按分值口径的百分比。
- 健康度：近期每天推进几档、按期每天需要几档、比值和判词；不出比值时的原因和原始数。
- 有效学习时长：每天的在场、有效、待检测分钟数；待检测涉及哪几节、要补几道检测题；有效学习日。
- 正确率：首次作答题数、答对题数、百分比；样本不够时只给原始数。
- 周报：给结论、只给数据、不生成三选一；本周有效学习时长、推进的档（附上周的）、预测变化。
- 页面上：S06 三个数卡片（显示哪一科见 R4）；S24 总览的三个数、预测走势、各科进度、有效与在场；S08 本周一句话和三个统计（有效 / 在场、工作量、预测变化）。离线时显示上次的结果和计算时间。

## 规则（大白话，编号）

通用

R1 数字只从这里来：三个数、有效学习时长、有效学习日、正确率都由后端按本卡算好返回；页面、导师、周报只引用，不重算、不改动（红线 5）。AI 可以润色说明文字，数字原样照抄。
R2 按目标分别算。“今天”“本周”按学员时区和日界线（默认北京时间凌晨 4 点）用同一个“今天”函数算；周是周一到周日的自然周。
R3 算哪些知识点：完成度和健康度只算学习范围内（跟随默认＋我加入）、有目标档的知识点；我移出的不算工作量，但照样进预测（R6）；积累拓展型不设目标档，三个数都不算。档一律用系统判定档，不用自评档。
R4 分科：评价规则是“每科都要过”的考试，每科单独算三个数。S06 卡片和 S24 头部显示差距最大的那一科，并写上科目名（R06-Q1＝A）；差距一样取完成度低的，再按考试画像里的科目顺序；预测锁定、没有差距时取完成度最低的。不分科计分、或只有一科的考试，整张地图当一科算，不写科目名。S24 各科进度表每科一行，到了的写“已过目标线”，没到的写“差 N 分”。
R5 还没摸底、也没有任何证据时，三个数都不出（空态“完成摸底后出现三个数”）。

预测与差额（够不够）

R6 最可能值：每个知识点按系统判定档查“预期得分率”（参数 learner.forecast.level_rates，0 到 5 档依次 0.20、0.35、0.50、0.70、0.85、0.95），按权重加权平均，再乘满分。权重用考情给的预期分值；考情还没到“可参考”（冷启动、成熟中）时改用重要度 1–4，并标“按重要度估算”（S24-06）。移出学习范围的知识点照样算（考试照样考），按它现在的档；积累拓展型不算。
R7 区间：每个知识点的得分率上下浮动一个幅度（参数 learner.forecast.band_halfwidth）：证据充分 ±0.04；证据不足、同类考生够 200 人（learner.prior.min_population）时改用同类考生的平均得分率，±0.10；证据不足又没有足够的同类考生，按自己的档，±0.15。每个知识点的上下沿夹在 0 到 1 之间，同样加权、乘满分，得到保守值和乐观值。
R8 取整：最可能值四舍五入到整分（.5 进位）；保守值往下取整、乐观值往上取整，区间只放宽不收窄；都在 0 到满分之间。
R9 差额＝目标分 − 最可能值（取整后）。比的是学员自己的目标分，不是合格线；差额 ≤ 0 时不显示负数，显示“已过目标线”（R06-Q4＝A）。
R10 两种口径都给，并写明是哪种。
R10a 按今天的水平：三个数卡片用这个。
R10b 按计划学到目标日：假设学习范围内还没到目标档的知识点都学到了目标档，这部分按目标档算、幅度 ±0.06；其余不变。这是“照计划做完”的情景，不是承诺（S24 预测走势写着“不给通过承诺”）。
R11 置信度看区间宽度：（乐观 − 保守）÷ 满分不超过 6% 为“高”，不超过 12% 为“中”，更宽为“低”，页面标“低置信”（参数 learner.forecast.confidence_width_ratio）。有知识点用同类考生数据或默认估计代替时，同时给出这部分分值的占比，说明区间为什么变宽（只做快速定位时就会这样，S04-03）。
R12 锁定：地图体检不通过时，预测、差额、较上周都不出，写明原因并给修复入口；完成度、健康度照常（S24-07）。
R13 较上周＝现在的最可能值 − 上周最后一条预测记录的最可能值（本周一日界线之前的最后一条，“按今天的水平”）。本周之前没有记录、或那条是锁定的，就不显示，所以新用户第一周不显示。周报里的“预测变化”用同一个数（待拍板：R06-Q8，暂按 A）。
R14 预测记录：每次重算后，取整后的值、置信度或权重依据有变化，就追加一条（带规则版本、参数版本），只追加不修改。预测走势每天取当天最后一条，没有就沿用前一天。考后回填成绩时，拿考试日前最后一条“按今天的水平”的记录看成绩落没落在区间里；落在区间里的比例目标是 80%（learner.forecast.coverage_target），只用来监控和调参数，不参与算区间。

完成度（走了多远）

R15 完成度＝范围内各知识点“已到手的档”之和 ÷ 目标档之和。已到手的档＝系统判定档和目标档取小，超过目标档不多算；从 0 档算起，原来就会的也算走过的路（R06-Q2＝A）。
R16 按分值口径（S24-01 可切换）：每个知识点的完成比例（已到手的档 ÷ 目标档）按 R6 的权重加权平均。
R17 显示整数百分比，往下取整：没有全部到目标档就不会显示 100%。范围里没有可算的知识点时不出（空态）。

健康度（来不来得及）

R18 推进量＝一段时间里，范围内各知识点“已到手的档”的净变化之和。前后都按现在的学习范围和现在的目标档算：加入或移出范围、改目标档本身都不算推进；掉了档会抵掉推进。
R19 近期速度＝最近 7 个自然日（不含今天，今天还没过完；参数 plan.health.window_days）的推进量 ÷ 其中可学的天数。不可学日不算天数，但那天学到的照样算（R06-Q3＝A）。净推进是负数时按 0 算，并给出“有知识点掉档”的原因。
R20 需要速度＝还差的档（范围内“目标档 − 现在的档”，小于 0 按 0，求和）÷ 剩余可学天数（今天到目标日前一天，去掉已标的不可学日和周时间格里为 0 的日子）。
R21 健康度＝近期速度 ÷ 需要速度，保留两位小数。判词：1.0 及以上“来得及”，0.8 到 1.0 之间“有点紧”，0.8 以下“来不及”（参数 plan.health.verdict_levels，正好在分界上的归上一档）。卡片同时写两个速度，如“按期需要每天 1.4 档，近 7 天每天 1.71 档”。文案不用“落后”。
R22 不出比值的情况：开始学习不满 7 天，或 7 天里可学的天数少于 3 天（plan.health.min_days）→ 数据不足，只给“几天推进了几档”；范围内都已到目标档 → 显示“都已到目标档”；目标日已过或没有剩余可学天数 → 不出。

有效学习时长与有效学习日（投入了多少、学了几天）

R23 在场时长：学习类活动（做题、复习卡片、背诵、阅读、视听、读后即测、模考、主观题、口头训练、问导师）的页面在前台且有操作、或正在播放的时间。同一项活动中间停顿不超过 5 分钟算同一段，停顿也算；超过就断开，停顿不算（learner.effective.idle_gap_minutes）。几台设备同时开着，重叠的时间只算一次。自习室专注时长不算；今日页、地图、设置这类浏览也不算。
R24 有效学习时长：一段里产生了至少一条没撤回的证据，整段算有效。答错的负证据、待验证的证据都算；秒评、手动勾选“看过”、没确认的即时题都不是证据。证据后来被撤回，这一段重新判定。重叠的时间按“有效、待检测、其他”的先后只算一次。
R25 待检测：读完、看完但还没做这一节读后即测（视听是片内检测）的那段，先算在场，标“待检测”。7 天内（learner.effective.makeup_days）补做，原来那段转为有效、算在原来那天；超过 7 天再补，只有补做本身算有效，原来那段也不再算待检测（R06-Q6＝B）。
R26 读后即测没通过：读的时间照样算有效（有证据），只是这一节不算“完成”（待拍板：R06-Q7，暂按 A）。
R27 跨过日界线的一段按时间切到两天，有效与否按整段定。有效学习日＝这一天的有效学习时长大于 0；补做检测转为有效后，原来那天也补成有效学习日。周有效学习日数＝自然周里的有效学习日数。时长按分钟累计，显示小时时保留一位小数。

正确率（做得对不对）

R28 正确率＝首次作答答对的题数 ÷ 首次作答的题数（R06-Q5＝A）。同一道题（按题目编号，改版也算同一题）只算第一次，错题回炉、重做都不算；变式题是另一道题，算它自己的第一次。
R29 不进正确率：没确认的即时题（四级）；主观题（按得分率另算，不在本卡）；因为题目报错改正而撤回的作答，这道题整个拿掉，改好后再做的那次也不补成第一次。
R30 首次作答少于 10 题（practice.accuracy.min_attempts）→ 数据不足，只显示“做了 n 题、对 m 题”。显示整数百分比，四舍五入。

周报（S08）

R31 周报看本自然周：有效学习日少于 3 天（plan.report.min_days）→ 不生成（空态“至少有 3 天学习记录后生成周报”）；够 3 天但有效学习不足 120 分钟（plan.report.min_effective_minutes）→ 只给数据、不给结论（不出一句话总结、亮点、教练点评）；都够才给结论。
R32 投入产出（S08-02）：本周有效学习时长；本周推进的档（同 R18，从本周一日界线到现在），附上周的数；本周预测变化（同 R13）。
