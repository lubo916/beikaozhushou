# 黄金路径（6 条）

> 冒烟测试与走查的依据。阶段 1 只检查页面跳转和关键元素出现；阶段 2 接后端后补数据断言（任务 B21 全绿）。
> 每条用演示考试 kj（初级会计）走，手机 375 与桌面 1280 各一遍。
> 首批邀请版本（开工决定第 2 条：日循环、入门、账号接通）以 G1–G4 全绿为门槛。

## G1 首次使用

S01 选年龄段 → “先体验，不注册” → S02 选“初级会计职称” → S03 只填“每天学多久” → S04 选“快速定位”（按章自评为主、少量题为辅），做完 → S05 看起点报告，在三档方案（稳妥、标准、冲刺）里选“标准”，点“生成我的计划”（此处要求登录）→ 登录 → S06 今日（首次进入视图）。

断言（阶段 2）：游客数据并入正式账号；今日清单有三段；三个数有值或显示“数据不足”（首日不显示“较上周”）。

## G2 一天

S06 今日 → 巩固段“到期复习” → S15 复习会话（翻面、评分）→ 回到今日，该项显示已完成 → “错题回炉” → S18 做题 → 推进段“新学” → S12 阅读 ＋ 读后即测 → 今日“全部完成”视图。

断言：完成判定只认证据；实际用时被记录；全部完成后明天清单可预览。

## G3 做题到地图变色

S17 练习中心 → 开始一组练习 → S18 作答、选把握度、提交、看分层揭晓 → S10 知识点主页“我的证据”出现这次作答 → S09 方格颜色更新。

断言：蒙对不升档、进“待验证”；证据不足的格子画虚线，与“未学”分开；档位依据可展开查看。

## G4 错题闭环

S18 做错一题 → S19 错题本出现（新增）→ 确认错因 → 时间推进到到期日 → S06 巩固段出现“错题回炉” → 按回炉间隔逐次做对，直到满足毕业条件（默认间隔做对 2 次，再做对 1 道变式题；数字来自参数）→ S19 显示已毕业。

断言：四个状态按规则卡 R03 流转；毕业条件可配置。

## G5 模考到计划

S22 模考中心 → 开考确认 → 作答（导师与搜索暂停）→ 交卷 → S23 测评报告 → “补强清单加入计划” → S07 出现待确认提议 → 确认后今日清单变化。

断言：计时以服务器为准；断点续考答案不丢；提议确认前计划不变。

## G6 问导师

S18 揭晓后“讲解与追问” → S28 导师回答带出处与“AI 生成”标识 → “生成卡片” → 卡片进 S15 待确认区 → 收下后进入复习队列。

断言：导师不能直接改计划与卡片；导师不可用时 S06、S15 照常可用。
