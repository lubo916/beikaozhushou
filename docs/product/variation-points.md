# 扩展点登记

考试之间的差异只能出现在考试画像数据（contracts/exam-profile.schema.json）或下表登记的扩展点中；核心领域代码不按考试写分支（INV-26）。新增扩展点走重型通道。

| 扩展点 | 位置 | 适用考试类型 |
|---|---|---|
| 评价规则 | exam-profile 的 evaluation_rule（合格线型、择优型、分数段型、自定型），由 exam 领域解释 | 全部考试 |
| 题型与作答形态 | exam-profile 的 question_types，作答形态取 glossary 的九种之一，practice 按作答形态渲染与判分 | 全部考试 |
| 知识类型的默认学法与目标档 | map 领域的知识类型库（九类），按知识点类型取默认，不按考试 | 全部考试 |
| 主观题评分细则 | grading 领域的评分细则来源（官方、模板、用户提供），一致性不达标只给要点不给分 | 含主观题的考试 |
| 口头表达评估 | 扩展包挂载 oral_assessment，grading 领域的多维评估维度由画像配置 | 面试、口语类考试 |
| 报考决策数据 | 扩展包挂载 admission_decision，只在有招录、升学数据的考试出现（S26-01） | 招录、升学类考试 |
| 听力与音频材料 | 作答形态 listening，content 领域的音频播放与时间轴 | 语言类考试 |
