# PLAT-01 学员端外壳与通用状态组件

## 1 目标与边界
学员端有一个按原型导航结构组织的外壳：手机、平板、桌面三种宽度下都能经导航到达 R1 所列的全部页面，入门流程与扩展页经各自地址打开；页面先放占位。packages/ui 提供各页共用的状态组件，以及提议卡与撤销条的骨架；任一页面用一行代码即可切到加载、空、出错态。

不做：页面内容；机构端与后台外壳；账号卡、备考目标切换、随手记、导师浮标与导师面板（由各自功能接入）；扩展页 S21、S26 的入口（随考试扩展挂载接入）；外观与无障碍设置界面（ACCT-09）；离线能力。

## 2 业务规则
- R1 导航（ADR-017 决定 7）的分组、组内顺序与分组字徽取原型，页面名称取页面登记的 title：今日（今）S06、S07、S08；学（学）S09 至 S14；记（记）S15、S16；练（练）S17 至 S20；考（考）S22 至 S25、S27；助（助）S28 至 S30；我（我）S34、S31、S32、S33、S35。S01 至 S05 不进导航。手机底栏五个入口及其分组：今日（今）→ S06，今日组；学习（学）→ S09，学、记；练测（练）→ S17，练、考；导师（导）→ S28，助；我的（我）→ S34，我。当前页所在分组属于哪个入口，该入口即为选中态。
- R2 三档按外壳容器宽度与令牌 size.breakpoint.tablet、size.breakpoint.desktop 判定，用容器查询实现（ADR-029）。手机：顶栏（目录按钮、页名）与底栏；目录按钮从左侧拉出抽屉，按 R1 列出全部分组，背后有遮罩。平板：左侧图标栏，每组一个字徽按钮，点开在旁边弹出该组的页面列表，只有一页的组直接跳转。桌面：左侧分组侧栏，列出组名与页面。平板与桌面的顶栏显示组名与页名。三档都标出当前页与所在分组。顶栏右侧有“搜索”（S29）与“消息”（S35），手机只显示“消息”。抽屉与弹出列表打开时焦点移入，Esc 或点遮罩关闭，焦点回到触发它的按钮；路由变化时自动关闭。
- R3 S01 至 S35 每页有一个路由，显示外壳与占位：页名与“尚未开放”。根路径进入 S06；未知地址在 standard 外壳中显示“页面不存在”与“回到今日”，导航不选中任何项。启动时先检查浏览器能力（容器查询、color-mix、CSS.registerProperty），任一不支持时只显示“浏览器版本过旧”提示并列出 ADR-029 的浏览器下限，不启动应用。
- R4 外壳按页面登记的 mode 呈现：standard 有导航与顶栏；guided 隐藏导航，顶栏只有品牌与页面提供的步骤条；standalone 隐藏导航，顶栏只有居中的品牌；immersive 导航与顶栏都隐藏。guided、immersive 与 standalone 页的占位有“返回”，回到上一个 standard 页，没有则回 S06。
- R5 状态组件按 state 呈现，文案由调用方以文案键传入：loading 显示骨架，持续达到 ui.loading.slow_hint_seconds 后加一行“仍在加载”，离开时清除计时；empty 显示原因与一个下一步动作；error 显示“〈页名〉的数据暂时没取到：网络或服务异常。已保存的内容不受影响，点“重试”即可；连续失败会自动上报。”与“重试”；offline、restricted、insufficient_data、locked 显示说明与可选动作；normal 直接显示内容。“重试”执行期间按钮不可再点；重试仍然失败时调用一次上报回调，只带页面 ID 与错误码（接口错误体中的 code，没有错误体时为 unknown）；首次进入出错态不上报。
- R6 提议卡显示改什么、为什么、代价、不改会怎样，以及“确认”“不改”，只回调，不自行写任何学员状态。撤销条显示剩余撤销时间：不少于一天按天、不少于一小时按小时，都向下取整；不足一小时按分钟，向上取整；到期显示“已过撤销期”并停用“撤销”。
- R7 演示页 /demo 只在非生产构建中存在：可切换七种 state（含慢加载、重试失败）、四种 mode（guided 带示例步骤）与 R9 的外观组合；提议卡确认后出现撤销条，截止时间为确认时刻加 plan.proposal.undo_days 天，撤销后回到待确认。演示只改页面内存状态，不发写请求。
- R8 学员端启动时，以及从后台回到前台时，经 trackEvent 上报一次 app_opened，entry 为当时所在页的页面 ID（演示页为 demo，未知地址为 unknown）；只切换路由不上报；上报失败不重试，也不影响外壳。
- R9 颜色、字号、间距、圆角与尺寸只用 design/tokens.json 的令牌，外壳尺寸先登记再使用。外观有浅色与深色两套，默认跟随系统且随系统切换，深色取值作为修饰器登记在 tokens.resolver.json。浅色、深色各自再叠加色觉友好与大字号修饰器时，对比度都满足 WCAG 2.2 AA：正文 4.5:1，控件边界与焦点 3:1。可点元素都能用键盘到达与操作，焦点可见并有可读名称，字徽按钮带 aria-label。

## 3 界面
布局参考 S06（首页）。占位页不实现页面登记中的 states 与 state_overrides，由各页的功能实现；状态组件在演示页验收。外壳尺寸（侧栏、图标栏、顶栏、抽屉、弹出列表、底栏）取原型外壳的取值，登记为令牌后使用。

## 4 数据
不新增表与接口。页面名称与 mode 读取 0.1b 由页面登记生成的页面清单。状态组件、提议卡与撤销条在 packages/ui，不读取参数与接口，所需取值（慢加载秒数、截止时间、文案）由调用方传入；外壳、路由、演示页与学员端文案在 apps/learner。

## 5 AI 行为
无。AI 来源的提议卡与生成内容标识随 TUTOR-01 接入。

## 6 验收
PLAT-01-AC1（R1、R2）
Given 外壳在 375、834、1280 宽度，以及 size.breakpoint.* 两个断点各自两侧的宽度运行
When 逐档查看导航并打开抽屉、弹出列表
Then 依次呈现底栏加抽屉、图标栏加弹出列表、分组侧栏；三档能到达的页面集合都等于 R1；当前页、所在分组与底栏入口的选中态正确

PLAT-01-AC2（R3）
Given 外壳运行
When 打开根路径、/s10 与一个未知地址
Then 根路径进入 S06；/s10 显示外壳与“知识点主页”“尚未开放”；未知地址显示“页面不存在”与“回到今日”

PLAT-01-AC3（R4）
Given 先打开 S09，再依次打开 S03（guided）、S01（standalone）、S18（immersive）
When 查看各页外壳，并在每页点“返回”
Then 导航、顶栏与品牌按 R4 显示或隐藏；每次“返回”都回到 S09

PLAT-01-AC4（R5）
Given 状态组件与可推进的替身时钟
When 进入 loading 并推进到 ui.loading.slow_hint_seconds 前后；切到 empty、error；点“重试”且连续失败两次
Then 达到该秒数才出现“仍在加载”；empty 有原因与下一步动作；error 文案与“重试”齐全；重试执行中按钮不可点；首次出错不上报，两次重试失败各上报一次，只带页面 ID 与错误码

PLAT-01-AC5（R6）
Given 提议卡与撤销条
When 点“确认”与“不改”；把截止时间依次设为剩一天五小时、五小时三十分、十分钟、三十秒与已过
Then 两个回调各触发一次、没有写请求；剩余时间依次显示为一天、五小时、十分钟、一分钟、已过撤销期，最后一种“撤销”停用

PLAT-01-AC6（R7）
Given 预发构建与生产构建
When 分别访问 /demo
Then 预发可切换七种 state、四种 mode 与外观组合，确认后撤销条截止时间为确认时刻加 plan.proposal.undo_days 天，撤销后回到待确认；生产构建显示“页面不存在”

PLAT-01-AC7（R8）
Given 学员端在 S09 打开
When 切换几次路由，切到后台再回前台；之后让上报接口失败再回一次前台
Then 共上报三次 app_opened，entry 依次为 S09、当时所在页、当时所在页；切换路由不上报；接口失败时外壳照常可用

PLAT-01-AC8（R9）
Given 浅色、深色分别叠加默认、色觉友好、大字号修饰器的各组合
When 运行令牌对比度测试，并在 375 与 1280 宽度对 S06 占位页与 /demo 截图
Then 对比度全部满足 R9；截图与人工确认过的基线一致；源码里没有令牌以外的颜色与尺寸字面量

PLAT-01-AC9（R2、R9）
Given 只用键盘
When 遍历三档导航，打开再关闭抽屉与弹出列表，操作重试、确认、不改与撤销
Then 每个焦点可见且有可读名称；Esc 与遮罩都能关闭；关闭后焦点回到触发按钮

PLAT-01-AC10（R3）
Given 浏览器能力检查返回不支持
When 打开学员端
Then 只显示“浏览器版本过旧”提示，应用没有挂载
