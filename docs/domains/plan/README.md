# plan：计划引擎

## 要点

- 职责：目标与时间预算、今日清单（巩固、推进、收尾三段）、到期队列接口、轮次与学习范围、提议与重排记录、复盘与校准。算法见 docs/models/planner.md。
- 计划引擎是确定性算法，不依赖大模型（INV-04），是唯一能自动顺延的执行者（INV-01）；目标、范围、轮次的变更只以提议出现（ADR-013）。
- 到期队列的接口在本领域定义，错题、卡片、背诵等到期项由 practice 实现并注册。
- 时间预算为学员级一份，机构作业与课表以占用表达，个人任务避让（ADR-016）。
- 理由文案中的数字只来自引擎输出（INV-02）；每次变动写入重排记录，可撤销（INV-27）。
