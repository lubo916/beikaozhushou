# R04 第 2 轮的四项规则决定：全部按推荐

- 日期：2026-10-21　来源：R04-Q7 至 R04-Q10（用户在 R04 第 2 轮对话里回复“都按推荐”）
- 背景：复核指出时间不够时谁先让、锁定任务放不下、系统里没有作答或阅读记录的机构与自定任务怎么算完成，这几处没写清，需要产品负责人定。
- 决定 7–8：Q7＝A 时间不够时按“巩固保底 → 口述回顾 → 周复盘 → 锁定任务 → 巩固段其余 → 其他推进任务 → 补巩固”一条队伍排，个人合计不超过当天可用时间，周复盘放不下就这周不排；Q8＝A 锁定任务当天放不下就当场出“排不下”提议，确认前不排，选“不改”回到计划里待排。
- 决定 9–10：Q9＝A 这类机构任务以机构端的出勤、提交、批改记录为准，学员点“做完了”只记“自报做完”，都不进完成率；Q10＝A 这类自定任务点“做完了”记“自报做完”，不再顺延，不算学习证据、不进完成率。
- 影响：规则卡 R1、R2、R5、R15、R18、R19、R20、R22 与例子 E35、E38、E41、E42 已按此写；整卡仍是草稿，定稿要单独说“规则确认 R04”；“自报做完”的代码待术语表登记。
