# R07：纸笔成绩与跨设备补交

- 日期：2026-10-21；来源：用户回复“Q8 选 A，补交选 A”。
- 背景：R07-Q8 尚未决定；R16 与 R17 缺少新设备交卷后旧设备才补交的结算口径。
- 决定一：R07-Q8＝A；纸笔模式的全真套卷、半卷成绩进入趋势和预测，并标注“纸笔，用时由自己掌握”。
- 决定二：跨设备补交＝A；仍有待同步的旧设备时，当前设备交卷或到点后先等补交；全部补交完成或既有补交期限到达后，才最终结算定分。
- 边界：保留接管前答案有效、接管后答案拒收、同题按最后一次有效保存取值；结算前不揭晓答案，最终结算后迟到或重复补交不改正式分、不重复生成证据。
- 影响：R07 第二轮对齐 R12、R16～R18、R24、R28、R37；同步补上跨设备等待、期限到达、重复补交和纸笔截止后期限前上传的规则表与 JSON 例子。
- 定稿：以上是两项业务拍板；整张规则卡仍为草稿，完成补充修订后另行确认。
