# 决定卡 U06b 第 1 轮：手机上“几条调整待你确认”那一行在哪些视图出现

- 背景：bk spec 写手机布局是“英雄区 → 待确认提议（若有，置顶一行）→ 清单 → 三个数折叠成一行摘要”；原型截图只在正常视图画了这一行，全部完成、今天不可学、中断回归、导师不可用四个视图里也有待确认的提议，却没画。
- 决定（产品负责人 2026-10-23 在对话里说“需要我拍板的问题不用问，直接按你的推荐继续”）：U06b-Q1＝A，只要有待确认的提议，手机上就在英雄区下面置顶这一行，不分视图，由接口数据决定。
- 影响：手机上那四个视图比原型截图多一行黄色提示；平板与桌面不显示这一行（提议在右栏或清单下面直接可见）。想改成只在正常视图出现（B），只需改 PendingPin 一处。
