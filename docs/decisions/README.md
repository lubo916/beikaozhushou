# 决定卡

> 你拍板过的事，一事一张卡，文件名 `D-<YYYYMMDD>-<短名>.md`（如 `D-20261021-day-boundary.md`）。
> AI 在你回答问题后写卡；冲突时，决定卡的效力高于 docs/baseline 和原型，低于 AGENTS.md 的红线。
> V3 的 ADR 仍在 docs/adr/，作为历史决定，可以查但不再新增。

模板（10 行以内）：

```markdown
# <一句话决定>

- 日期：2026-10-21　来源：T032-Q1（交接单问题编号）
- 背景：为什么要定这件事（一两句）
- 决定：选了什么
- 影响：哪些页面、规则卡、代码要跟着改（已改／待改的任务编号）
```
