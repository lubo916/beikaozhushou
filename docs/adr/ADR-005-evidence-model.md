# ADR-005 证据模型

- 状态：已采纳

## 背景

一向门（分期规划 4.4）：证据怎么存，决定所有派生数据能否重算。掌握档、预测、计划都建立在“学员会不会”之上；原型只认能证明会或不会的行为，蒙对、秒答、用过提示的都要打折，生成题要先确认题目没问题。

## 决定

1. 证据是一次能证明会或不会的行为结果，以只追加的事件保存（evidence_events）：来源、题目与版本、可信度、对错、把握度、用时与提示等级；撤回写 revoke 事件。只由 learner 写入，经 evidence.recorded 发出，撤回发 evidence.revoked。
2. 计入证据：作答（含诊断、练习、模考、片内检测、读后即测）、复习回忆、背诵检测、主观题批改、自评后的检验题。在场时长、只阅读、只观看、自习室专注时长、手动勾选“看过”都不算证据。
3. 强度五级：强、中、弱、负、待验证。蒙对或秒答记待验证，用过提示降为弱，关闭把握度标注时正确作答最高记中，未确认的即时题不计。权重与门槛是参数，决策表见 docs/models/learner-model.md，定稿随 OQ-002（探针 0.4A）。
4. 升到“已掌握”及以上、或让错题毕业，须有不同题目的结果一致（异题印证，learner.mastery.cross_check_items）。
5. 掌握档是可随时从证据整体重算的派生快照。题目事后改了答案，由它产生的证据撤回并重算（ADR-010）。

## 后果

- 题目纠错与规则升级都能重算历史。
- 证据表增长快，按时间分区；判定规则改动影响全部学员，属重型通道。
- 何时重新考虑：真实数据显示某类行为的预测力与登记强度明显不符时，调整决策表与参数。
