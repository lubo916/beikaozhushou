# ADR-017 跨页口径裁决

- 状态：已采纳

## 背景

掌握档、错因、重要度等定义被多页共用，先开发的页会把它们写进表结构（doc-system 附录 M 第 2 步）。合并版原型与深化来源原型在其中几项上定义不同。按 ADR-001，业务口径以单一事实源为准，深化来源的界面与交互在深化各页时再采纳。

## 决定

1. 掌握档：六档（未学、已了解、已熟悉、已掌握、能应用、能迁移），只由证据判定。自评只显示，不直接改档位；自评“已掌握”时出检验题，通过才记证据。复习中不能手动改掌握档。
2. 错因：两层。第一层七类，每类对应补救动作；第二层为陷阱类型（类型库中称干扰模式），通用十二类加计算类、语言类分组，可扩展。测评报告的失分归因是另一套六类，不与错因混用。
3. 重要度：1–4 级，4 最重要，与考情级同一刻度；两层：官方或模板给默认值，学员可覆盖；个人星标是独立的标记。
4. 笔记类型：综合、口诀、释义、要点、易错五类；记在哪里（资料段落、题目、对话）是来源属性，不是类型。
5. 知识点身份：知识点是知识地图上有名称、有稳定 ID 的节点（ADR-009）；资料中的标题块与段落按置信度对齐到知识点，本身不是知识点。
6. 题型：十三种题型映射到九种作答形态；各考试的题型名经画像映射。
7. 学员端导航以今日清单为首页，底部五个入口加分组侧栏；资料与题库的目录树是“我的资料”内的视图，不作全局导航。
8. 不设连续打卡、等级与保护卡；里程碑只认真实进步。

## 后果

- 表结构与算法规格从第一天就只有一个版本；取值写在 glossary.yaml。
- 深化来源中依赖其他口径的交互（例如复习中改掌握度、按五级重要度着色）在深化时要改写。
- 何时重新考虑：要采纳深化来源的某项做法时，按重型通道修改术语表、算法规格与本 ADR。
