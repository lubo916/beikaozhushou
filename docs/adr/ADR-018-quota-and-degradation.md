# ADR-018 额度与降级

- 状态：已采纳

## 背景

收费必须有限制，但限制若落在核心闭环上，学员会因为没续费而中断复习与回炉，这与产品承诺相反（S31-02、P19-06、P10-04）。深化来源的做法是对题量、错题本、收藏、试卷、闪卡与决策页逐项设上限并按档位锁定。

## 决定

1. 核心闭环（今日清单、计划、到期复习、错题回炉）在任何档位都不限量（INV-18）。
2. 只限两类：规模类（同时进行的目标数、资料解析量、存储）与高成本 AI 类（按 AI 点数计量的导师深度能力、批改、错题分析、即时出题等）。
3. 额度用完只暂停高成本 AI，其余照常；触限时统一说明用完的是哪一项、何时恢复、升级或加量后能用多少，并给不花钱的替代。
4. 会员到期后数据全部可见、可导出；超出免费规模的部分转只读，不锁定、不删除。
5. 额度数值、提醒阈值（billing.quota.remind_at）与回收站保留期都是参数，不按档位写在代码里；涉及额度扣减的写操作在数据库中原子完成。

## 后果

- 付费墙不会切断学习；额度规则集中在 billing 与参数中心。
- 免费用户的存储与解析成本由规模类额度控制。
- 何时重新考虑：真实成本数据显示某项非核心能力必须限量时，按重型通道把它登记为规模类额度。
