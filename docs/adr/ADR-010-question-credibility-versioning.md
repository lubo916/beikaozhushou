# ADR-010 题目可信度与版本

- 状态：已采纳

## 背景

一向门：生成题与自有题会越来越多，题目来源决定作答能记多强的证据（S17-05）。题目纠错后，历史作答要能对应到学员当时看到的版本；模考开考后题目改动不能影响本场。

## 决定

1. 题目带可信度：审定题、自有题、已确认的生成题、未确认的即时题。每级的证据强度上限为参数 learner.evidence.credibility_caps；已确认的生成题同时满足先做后核、质检通过、有出处时，上限与审定题相同。
2. 已发布的题目被修改时生成新版本；作答记录、试卷快照与证据都关联题目版本。
3. 作答记录只追加：逐题记录提交时间、用时、把握度、提示使用、答案原文与题目版本。
4. 模考与班级考试开考时冻结试卷快照。
5. 题目答案被修订时，由旧版本产生的证据经 learner 撤回并重算，受影响的学员收到通知（S18-26）。

## 后果

- 可信度升级（P08）走审核；未确认的即时题不能把知识点推到“已掌握”。
- 存储增长；查询“当前题目”与“历史题目”要区分版本。
