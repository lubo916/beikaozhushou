# ADR-016 时间预算模型可被多目标与机构任务共享

- 状态：已采纳

## 背景

一向门：学员可能同时备考多个目标（S02-12），机构作业与课表也会进入今日（O05-01、O06-05）；各自安排时间会互相冲突。

## 决定

1. 时间预算是学员级的一份（time_budgets），来自时间格或每日目标时长。
2. 目标的学习任务、机构作业与课表都以占用（time_reservations）表达。
3. 计划引擎先扣除占用再排个人任务，个人任务自动避让；机构布置作业时能看到班级本周的剩余可用时间。

## 后果

5 期的多目标与 7 期的机构任务接入时不改预算模型；占用冲突以提议告知学员。
