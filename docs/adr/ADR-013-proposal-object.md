# ADR-013 提议作为一等对象

- 状态：已采纳

## 背景

一向门：计划、复盘、测评、导师都需要改计划；如果各自直接改，计划既无法解释也无法撤销（S06-10、S07-10、INV-01）。

## 决定

1. 对学员状态的变更（目标、范围、轮次、补强、冲刺等）以提议对象表达（proposals 表），写明改什么、为什么、代价、不改会怎样。
2. 状态为待确认、已采纳、已拒绝、自动执行、已撤销、已过期。
3. 只有计划引擎的夜间顺延可以自动执行，并在 plan.proposal.undo_days 天内可撤销；所有变动写入重排记录。

## 后果

AI 执行者对计划的写权限一律为 propose（E-AI-03）；提议卡是 packages/ui 的通用组件。
