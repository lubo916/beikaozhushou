# ADR-011 租户归属与数据隔离

- 状态：已采纳；决定 2、3 由 ADR-028 取代

## 背景

一向门：机构端会共用学员端的数据表，后加隔离要改全部查询（分期规划 4.4）。隔离若只靠应用层的查询条件，一处遗漏就是越权。

## 决定

1. 每张业务表都有 tenant_id：个人学员的数据归平台默认租户；机构布置的作业、班级考试等机构任务数据归机构租户。学员与机构的关系由班级成员与授权记录表达，不把个人数据复制进机构租户。
2. 数据库启用行级安全：应用连接使用无绕过权限的角色，每个请求在事务内设置当前用户与租户；跨租户的运营操作只在后台服务端代码路径中使用专门角色。
3. 应用层查询照写用户与租户条件，行级安全兜底。
4. 平台人员访问机构数据须审批并留痕（P14-03）。

## 后果

- 0 期起所有业务表就带 tenant_id，7 期接入机构时不改表结构。
- 查询必须在设置了上下文的事务中执行；测试要覆盖跨租户读取被拒。
- 何时重新考虑：单个机构的数据量需要独立部署时，评估按租户分库。
