# ADR-014 参数外置为注册表

- 状态：已采纳

## 背景

一向门：原型把阈值、配比、上限都去了数值，要求集中成带默认值与说明的配置（分期规划 0.1e、P19-02、P19-05）；写死在代码里会与后台参数中心不一致。

## 决定

1. 参数登记在 contracts/params.yaml：名称、owner、说明、默认值、区间、单位、谁可调、学员可调区间、生效方式、是否须填理由，以及出处原型条目（source_items）。
2. gen 生成 packages/params/registry.generated.ts 的登记数据与类型，runtime.ts/index.ts 为消费该登记的手写访问器；拆分在 0.1b 完成。未登记参数报错，已登记默认由登记提供，不用字面量兜底；业务阈值只经访问器读取（E-PARAM-03）。
3. 后台参数中心以登记为种子，取值夹在登记区间内；需灰度的参数只走灰度。
4. 参数在被功能或算法规格用到时登记；默认值为临时默认（OQ-001），证据与掌握相关由探针 0.4A 定稿，记忆调度由 0.4B 定稿，排程由 0.4D 定稿。

## 后果

- 参数语义的变化属于重型通道。
- 说明与出处让后台参数中心（P19-02）能直接展示每个参数的依据。
