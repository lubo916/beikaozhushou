# ADR-009 知识点稳定身份、版本与合并拆分映射

- 状态：已采纳

## 背景

一向门：知识点 ID 一旦被证据引用，就不能随改名、移动而变；地图会更新，学习记录要能迁移（S09-08、S09-14）。

## 决定

1. 知识点 ID 为稳定的 UUID，不随名称、位置、版本改变，也不复用。
2. 地图有版本；节点记录 since_version 与 retired_in_version；改名、移动、合并、拆分、退役写入只追加的 knowledge_point_mappings。
3. 合并时学习记录汇总到新点；拆分时新点标“证据不足”而不清零。
4. 官方底图与个人、机构扩展层分开，官方节点只读。

## 后果

证据始终指向稳定 ID；迁移就是一次重算；8+ 的跨考试映射在此基础上扩展。
