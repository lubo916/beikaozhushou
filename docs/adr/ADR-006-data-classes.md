# ADR-006 数据类别与可见范围

- 状态：已采纳；决定 4 的标注写法随 ADR-026 的表结构转换改变

## 背景

一向门：数据四分类与逐项授权（原型 P18-10、S32-03、O04-01）。机构端要看学情才能督学，但学员不会接受机构看到一切；后补分类要改全部查询与界面。

## 决定

1. 学员数据分四类：机构任务（按入班约定可见）、个人学习（逐项授权，默认不勾）、推断（逐项授权）、敏感（个人笔记、情绪打卡、导师对话、危机记录，永不向机构开放）。
2. 另设账号与联系信息、公共内容、机构内容、运营与系统数据四个非学员类别，使每个字段都能标注。
3. 未授权的数据不显示、不参与任何排序与统计；学员撤回授权后，机构侧副本在 compliance.revoke.purge_days 天内删除，并向开放接口推送撤回事件（INV-07）。
4. 类别登记在 contracts/data-classes.yaml；schema 的每个字段标 x-data-class（E-DC-01）；机构端读取学员数据一律经可见性组件；AI 执行者的可读范围以类别声明在 contracts/ai/actors.yaml。

## 后果

- 可见性由检查与组件机械保证，不靠逐页判断。
- 新增字段先归类；新增数据类别属于重型通道。
