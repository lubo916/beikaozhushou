# ADR-019 AI 导师面板的归属与契约

- 状态：已采纳

## 背景

导师出现在完整对话页、每页右下角浮标、页内侧栏三处，阅读器中又与讲解面板合一（S12-21）。若每页各写一套面板，上下文、记忆与标识规则会分叉。

## 决定

1. 导师面板是共享组件：界面在 packages/ui，契约（页面上下文的结构、写操作提议的格式、降级与标识）归 tutor 领域。
2. 三种形态共用同一份上下文与记忆；页面只提供“当前上下文”（题目、所选项、段落、视频时刻、知识点），不自行拼提示词。
3. 阅读器中导师就是右侧“讲解”标签，不另开抽屉。
4. 引导页、独立页、测评态视图以及机构端、后台不出现导师入口（INV-20）；机构助教是另一个执行者，界面明示“机构助教，机构可见”。
5. 面板中的写操作一律生成待确认提议（INV-01、INV-03）；所有回答带生成内容标识（INV-05）；不可用时说明暂停范围并给替代做法（INV-04）。

## 后果

- 上下文注入、标识与降级只实现一次。
- 各页要按契约提供上下文对象。
- 何时重新考虑：出现无法用上下文对象表达的页面需求时，扩展契约而不是在页面里写特例。
