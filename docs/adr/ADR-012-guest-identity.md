# ADR-012 游客身份与登录后合并

- 状态：已采纳

## 背景

一向门：“先体验后注册”（S01-01、S01-13）要求游客期间的目标、摸底与学习记录在登录后并入正式账号；做成两套身份体系就合不起来。

## 决定

1. 游客与正式用户共用 users 表，以 kind 区分；游客产生的数据从一开始就以 users.id 归属。
2. 登录时，若手机号对应已有账号，就把游客数据并入该账号，并记录 merged_into 与 merged_at。
3. 合并不丢证据：冲突以正式账号已有数据为准，游客的证据作为补充写入。

## 后果

1 期即使不开放游客入口，表结构也已就位；2.1 只做流程与界面。
