# 学员端约定

## 规则
1. 页面按登记的 mode 实现：guided 带步骤条，引导流走完后隐藏入口；immersive 隐藏底部与侧栏导航；standalone 不带导航。
2. 今日清单、到期复习与错题回炉可离线完成，证据在联网后补记。
3. 地图体检不通过时（locked），S05–S10 与 S24 的预测类区块显示原因与“去修复”，学习功能照常。
4. 扩展包页（S21、S26）只在当前考试画像挂载了对应扩展时出现入口。

## 示例
- 正例：S18 做题与解析进入沉浸模式，隐藏底部五个入口；交卷后回到进入前的页面。
- 反例：S26 报考决策对所有考试显示入口：没有招录或升学数据的考试会看到空页（S26-01）。

## 理由
模式决定导航与注意力：引导页要走完，沉浸页要专注。离线可用的核心闭环是承诺（S06、S15、S19 的离线态），不能随网络中断。
