# 页面状态约定

## 规则
1. 每个业务页面和视图处理页面登记中 states 列出的全部状态；闭环 0.1 的 PLAT-01 五个纯外壳占位路由只显示标题与尚未开放，七态在演示页验收，业务页落地时恢复完整要求。
2. 进入加载态即显示骨架或保留内容，达到 ui.loading.slow_hint_seconds 后追加仍在加载的提示，不显示空白。
3. 空状态写明原因，并给出一个下一步动作。
4. 错误状态提供重试；已保存的内容不受影响，连续失败自动上报。
5. 离线状态说明哪些功能可用；核心闭环（今日、复习、错题回炉）离线可用。
6. 受限状态（权限或额度）说明原因与出路，不让人走进死胡同。
7. 数据不足状态说明还差多少数据，不显示无依据的结论。

## 示例
- 正例：S06 今日清单为空时显示“今天没有安排：目标日已过或还没生成计划”，并给出“生成计划”按钮（去 S05）。加载立即呈现骨架，慢加载提示的阈值取 ui.loading.slow_hint_seconds。
- 反例：S06 为空时只显示“暂无数据”：学员不知道发生了什么，也不知道下一步做什么。

## 理由
页面状态处理是最常被遗漏的部分；统一规则加上每页的状态例外，能让三端的表现一致，也让测试可以逐页核对。
