# 安全与隐私约定

## 规则
1. 每个接口在 contracts/permissions.yaml 中有对应动作，服务端按角色与数据范围校验，不依赖界面隐藏；接口默认要求登录，公开接口在 openapi.yaml 中显式标注；响应按字段白名单输出（ADR-027）。
2. 机构端读取学员数据一律经可见性过滤：机构任务数据按入班约定，个人学习与推断数据按逐项授权，敏感数据永不开放（INV-07）。
3. 手机号加密存储、按哈希查询，发短信前先过验证码并按参数限流；联系方式默认脱敏，查看完整信息须填事由并留痕（INV-13）。
4. 敏感操作写审计日志；平台人员访问机构数据须审批并留痕。
5. 密钥与令牌不进仓库、日志与浏览器存储，会话只放 HttpOnly Cookie；日志中的个人信息按数据类别脱敏。

## 示例
- 正例：O04 学员 360 顶部按四类数据列出“能看到什么、看不到什么”，掌握度分布已授权可见，预测分未授权不显示。
- 反例：班主任列表接口直接返回学员的导师对话摘要“方便督学”：敏感数据永不开放给机构。

## 理由
产品同时踩在教育培训、生成式人工智能、个人信息与预付费四条监管线上（P18）。可见性与留痕做在服务端和组件里，才不会因为某个页面漏写而泄露。
