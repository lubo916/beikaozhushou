# 响应式约定

## 规则
1. 学员端以手机为主：375 宽度下全部功能可达；平板与桌面复用同一页面，只改变布局。
2. 断点只用令牌 size.breakpoint.*，不写像素字面量。
3. 手机为底部五个入口、桌面为左侧导航，入口集合相同；沉浸模式隐藏两者。
4. 机构端与后台以桌面为主，1280 宽度下完整可用；手机上保证查看与处理待办。

## 示例
- 正例：S03 周时间格在手机上按天折叠成列表，桌面上铺开七列（S03-12）。
- 反例：S09 方格全景在手机上横向滚动铺满整张地图：手机默认应为大纲树（S09-18）。

## 理由
备考的碎片时间大多在手机上；桌面只是更宽的同一套页面。两套页面会让 AI 生成的代码分叉，状态与权限处理也要写两遍。
