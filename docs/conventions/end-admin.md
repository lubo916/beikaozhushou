# 平台后台约定

## 规则
1. 受限状态说明需要哪个后台角色，不显示任何数据。
2. 数据不足状态：样本量低于该指标在 contracts/metrics.yaml 登记的最小样本时，不出结论，只显示原始计数。
3. 后台需要联网：离线时只提示，不缓存数据。
4. 空状态提示“当前筛选下没有记录”，并给出更换筛选条件的入口。

## 示例
- 正例：P01 运营驾驶舱中“预测区间覆盖率”样本不足时显示“样本 37 个，暂不出结论”。
- 反例：P05 考情分析在冷启动阶段给出“本章命题趋势上升”：成熟度不足不展示（P05 页的成熟度门控）。

## 理由
后台的判断会传导到学员端（考情、预测、参数）；样本不足时的结论会被当成事实使用。
