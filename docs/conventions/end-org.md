# 机构端约定

## 规则
1. 受限状态：学员数据只显示已授权项，未授权的不显示、不参与统计。
2. 数据不足状态：人数少于参数 org.stats.min_class_size 的班级不显示汇总统计。
3. 离线状态：只能查看已缓存的待办与联系清单，提交与发布需要联网。
4. 空状态：还没有班级或学员数据时，引导先导入学员或建班（去 O03）。
5. 机构助教的回答在学员端标明“机构可见”，与个人导师分开（O10-03）。

## 示例
- 正例：O13 数据中心对 7 人的小班只显示原始名单，不显示平均掌握率。
- 反例：O03 分层列表把未授权“错题与错因”的学员计入“需关注”统计：未授权数据不得参与统计。

## 理由
机构端最常见的越界不是直接展示，而是通过汇总与分层间接推断出未授权的数据；小样本汇总同样能反推个人。
