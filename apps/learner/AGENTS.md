# 学员端（S01–S35）

## 本端要点
- 以手机为主，底部五个入口；平板与桌面是同一套页面的宽屏布局。
- 页面状态按 design/screens/learner/<页ID>.yaml 中的 states 实现，通用表现见 docs/conventions/ui-states.md。
- 未成年人模式由 account 领域给出开关，界面只读开关，不自行判断年龄。
- AI 内容一律使用带标识的 AI 内容组件；今日清单、到期复习、错题回炉的界面不因额度或 AI 不可用而隐藏（INV-18、INV-04）。

## Code Review Rules
- 新页面或新视图缺少登记中列出的状态处理。
- 未成年人模式下出现了该模式不允许的入口。
- AI 内容没有使用带标识的组件。
- 测评态视图里出现了导师、搜题或提示入口。
