1. 现有代码生成器只向 learner/public 输出 MSW 工作线程。任务内预备脚本把同一工作树生成的脚本原样复制到被忽略的 org/public，SHA256 必须一致；本次已核为 `d4689b9bd650d249a434a88c790d2f6694f53f0938c639f23738753226c9f4c3`。共享生成目标以后应补机构端输出，本轮没有改工具或手写工作线程。
2. 实测生成请求在当前 fetch 适配器中没有传出 query：浏览器 API URL 不含条件，导致七态和角色切换收到正常数据。本页仅在开发模式用请求头补传演示条件给 MSW，仍使用生成钩子，不手写 fetch。正式接口接通前应整合共享参数序列化，并移除临时演示补传；该补传不参与真实服务授权。
3. O01/runtime.tsx 暂供两页共用；更多机构页接入时，整合任务可把 QueryClientProvider 和一次性 MSW 启动移到机构 App 公共装配。
